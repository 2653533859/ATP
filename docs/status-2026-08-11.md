# 2026-08-11 修复状态与后续计划

本文是 `docs/q18-latest-status-2026-08-07.md` 的后续校正记录；旧文档中的历史测试数量和
覆盖率只代表当时的提交，不作为当前质量门禁结论。

## 本轮已修复

- 浏览器认证改为 HttpOnly access/refresh Cookie；前端不再把 JWT 写入 `localStorage`。
- WebSocket 浏览器连接不再把 JWT 放入 URL；服务端优先读取 Cookie，并暂时保留旧的查询参数
  回退以兼容外部非浏览器集成。
- 增加 `APP_AUTH_COOKIE_SECURE`、`APP_AUTH_COOKIE_SAMESITE`、`/auth/logout`，并保留 Bearer
  认证以支持 CLI/CI 客户端。
- 混合 Web/API/Android/iOS 套件由 `default` Worker 编排，设备子用例投递到 `android`/`ios`
  队列；纯设备套件仍进入对应专用队列，避免专用 Worker 父任务等待自身。
- 启动配置 UI 与 `.env.example` 对齐为 100 项，补充认证 Cookie、ADB 扫描方式、性能节点和
  混合套件子任务等待参数，并标明用途及可选/必填状态。
- Windows 冒烟脚本、性能验收脚本和 Q12 证据采集器改为兼容 Cookie 会话。
- APK、用例、套件、计划、iOS、通知、缺陷跟踪器、Mock、移动专项和统计列表统一按用户可见
  项目过滤；执行记录、报告导出、诊断、修复反馈、快照和移动专项详情增加资源级项目权限校验。
- Web 录制强制关联项目并要求编辑权限；当前镜像只支持 Chromium，因此 API 与 UI 移除无效的
  Firefox/WebKit 选项。录制 URL 和报告封面 URL 增加协议、凭据、显式 IP 与 DNS 解析地址校验，
  拒绝本机、私网、链路本地和保留地址。
- 移动专项停止操作增加 Redis 取消信号，性能、稳定性和流畅度执行器会在运行中轮询并终止；
  流畅度执行器的 ADB 操作移出异步事件循环。
- Android/iOS 设备租约在检查和创建前锁定设备行，避免并发申请时重复占用同一设备。
- 分页参数增加下界校验，修复两处乱码错误消息，并修复仓库中已有的 Ruff 格式门禁问题。

## 当前验证结果

- 后端非集成测试：`1761 passed`；逐文件独立扫描：`247 passed, 0 failed`。
- 后端覆盖率（本地 Python 3.14）：`80.09%`，低于仓库门禁 `82%`；需用 CI 口径 Python 3.12
  复验，但在补齐测试前不能宣称覆盖率门禁通过。
- 前端 Vitest：`37 files / 146 tests passed`；覆盖率为 statements `29.53%`、branches
  `24.87%`、functions `23.55%`、lines `30.56%`，低于 `31.5 / 26.5 / 24.5 / 32.5` 门禁。
- `make lint`、`make format-check`、`make mypy`、`npm run type-check`、`npm run build`：通过。
- 本文记录的是本次提交前的本地结果；真实 integration、物理设备、镜像扫描和部署验收尚未
  重跑，因此当前版本仍不满足发布条件。

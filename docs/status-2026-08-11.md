- 已补齐独立 Worker 入口、Windows `local-dev.cmd` 进程托管、Compose profile、Helm Deployment、启动配置 UI 和部署/故障排查文档。
- 已补充 API 远程路由、Worker 生命周期/容量、Redis 回复队列和部署静态契约回归；Linux/Xvfb、真实 Firefox/WebKit、跨 API 副本 E2E 仍待目标环境验收，因此 P1 仍保持“部分实现/待验收”。

本文是 `docs/q18-latest-status-2026-08-07.md` 的后续校正记录；旧文档中的历史测试数量和
覆盖率只代表当时的提交，不作为当前质量门禁结论。

- `local-dev.cmd doctor` 已覆盖 Web 录制 `local`/`worker` 模式、Python Playwright、Chromium 可执行文件，以及 Worker 入口、Redis 队列前缀和正整数并发上限。
- `scripts/windows-android-worker.ps1 doctor` 已覆盖 Celery/Redis Python 依赖和 ADB；该历史记录中的 k6/Locust 告警已由当前安装和真实平台执行验收关闭，当前仅保留 Android 未连接警告。
- Windows 冒烟新增 `-WebCaseId`、`-SeedWebDownloadCase`、`-RequireWebLowcode`、`-RequireWebDownload` 和超时参数，可从已认证会话触发已有 Web 低代码用例，或按需创建临时下载用例后轮询运行结果，并强制检查 download 步骤是否产生对象引用；不传 ID/seed 开关时保持跳过。
- PowerShell 解析和 Windows 合约测试通过；这项本地诊断不替代真实 Android 设备、Linux/Xvfb、跨副本 Web Worker 验收。

## 本轮新增：Android Agent 扫描状态回传

- `ADB_SCAN_MODE=worker` 的设备扫描现在返回任务 ID，设备页轮询 Celery 状态并在 Windows Worker 将结果写回 PostgreSQL 后再提示完成；`local` 模式仍同步执行。
- Windows Android Worker 启动时会注入稳定的 `ANDROID_WORKER_ID`，通过 Redis TTL 心跳注册；新增 `/devices/workers` 状态接口和设备页在线提示，普通 Worker 未配置 ID 时不会注册为 Android Agent。
- Windows 全量冒烟已接入 Worker 注册和扫描回调：worker 模式或 `-RequireAndroid` 下强制验证在线 Agent，并轮询设备扫描 task ID；无真实设备时只验证状态链路。
- 已覆盖 queued/running/completed/failed、无效 task ID 和 Worker 任务写回失败；真实设备连接与 Android 执行数据面仍需外部验收。

## 本轮已修复

前述 Android 设备矩阵并行调度、运行详情展示、报告导出、浏览器网络层隔离、覆盖率补强和低代码 Python 脚本生成已完成；当前最新本地验证以本文件“当前验证结果”章节为准。

- 浏览器认证改为 HttpOnly access/refresh Cookie；前端不再把 JWT 写入 `localStorage`。
- WebSocket 浏览器连接不再把 JWT 放入 URL；服务端优先读取 Cookie，并暂时保留旧的查询参数
  回退以兼容外部非浏览器集成。
- 增加 `APP_AUTH_COOKIE_SECURE`、`APP_AUTH_COOKIE_SAMESITE`、`/auth/logout`，并保留 Bearer
  认证以支持 CLI/CI 客户端。
- 混合 Web/API/Android/iOS 套件由 `default` Worker 编排，设备子用例投递到 `android`/`ios`
  队列；纯设备套件仍进入对应专用队列，避免专用 Worker 父任务等待自身。
- 启动配置 UI 与 `.env.example` 对齐为 100 项，补充认证 Cookie、ADB 扫描方式、性能节点和
  混合套件子任务等待参数，并标明用途及可选/必填状态。
- Windows 冒烟脚本、性能验收脚本和 Q12 证据采集器改为兼容 Cookie 会话。
- APK、用例、套件、计划、iOS、通知、缺陷跟踪器、Mock、移动专项和统计列表统一按用户可见
  项目过滤；执行记录、报告导出、诊断、修复反馈、快照和移动专项详情增加资源级项目权限校验。
- Web 录制强制关联项目并要求编辑权限；当前镜像只支持 Chromium，因此 API 与 UI 移除无效的
  Firefox/WebKit 选项。录制 URL 和报告封面 URL 增加协议、凭据、显式 IP 与 DNS 解析地址校验，
  拒绝本机、私网、链路本地和保留地址。
- Web 低代码执行与录制器新增共享 Playwright `BrowserContext` 路由守卫：每次导航、重定向、
  WebSocket 和子资源请求均重新做公网/DNS 校验，录制器默认拒绝内网 egress；`about:`、`data:`
  和 `blob:` 等浏览器内部协议不发起网络连接。被拦截请求只保存脱敏 URL、资源类型和原因。
- 移动专项停止操作增加 Redis 取消信号，性能、稳定性和流畅度执行器会在运行中轮询并终止；
  流畅度执行器的 ADB 操作移出异步事件循环。
- Android/iOS 设备租约在检查和创建前锁定设备行，避免并发申请时重复占用同一设备。
- 分页参数增加下界校验，修复两处乱码错误消息，并修复仓库中已有的 Ruff 格式门禁问题。

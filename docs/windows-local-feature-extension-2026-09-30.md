## 已接入的实现

| 功能 | 本地实现 | 使用限制 |
| --- | --- | --- |
| 手动套件 | SQLite 队列投递，子用例直接执行，串行进度和汇总报告 | 当前子用例结束后停止后续用例；取消显示为 error 并附取消说明 |
| 手动计划 | SQLite 队列投递，串行调用套件，运行中保存子套件关联 | 仅 manual；取消在当前套件结束后生效，不支持 Cron/Webhook |
| 需求、缺陷 | 开放已有本地数据库管理入口和运行证据关联 | 外部缺陷系统仍需用户独立配置，不自动沿用服务器凭据 |
| 测试资产 | 环境、变量、数据集、Web 元素/POM、API 契约可直接从菜单进入 | 文件走本地对象目录；本地不展示多用户管理 |
| 基础知识库 | 开放 SQLite 文本搜索和项目知识入口 | 数据与服务器独立 |
| AI 配置及用例生成 | 开放本地模型配置、AI 工作台，沿用加密凭据与现有生成服务 | 用户需配置并绑定本地模型；真实模型调用未验收 |
| GraphQL/WebSocket/gRPC | 解除本地用例类型限制，沿用现有执行器和本地队列 | 不支持 iOS；协议业务运行未验收 |
| Hermes | 开放现有项目检索、失败分析、报告查询与会话入口 | 当前工具以查询为主；真实模型及交互验收未完成 |
| 单机性能 | 性能任务进入 SQLite 队列；取消信号留在本机；结果走本地文件目录 | 不支持节点选择、分片和定时；依赖本机执行器 |

## 队列、迁移与模式边界

- 本地套件/计划强制串行，Android 子用例不再投递到同一个队列并等待，避免唯一执行线程被父任务占用。
- 创建子用例/子套件时先保存父子运行关联；异常退出后递归收敛未完成的子运行，并释放关联执行/设备租约，不重放可能有副作用的运行。
- SQLite 版本 5 扩展性能运行 ID 分配；版本 6 增加本地套件/计划取消记录。新库初始化与版本 4/5 的升级均有显式路径。没有改变服务器业务模型，不需要 PostgreSQL 表结构迁移。
- `/api/v1/runtime/capabilities` 提供功能与限制信息，前端启动时读取本地清单。
- 本地 `down` 终止已确认属于启动记录的进程树，覆盖其浏览器和压测子进程。
- 服务器继续使用配置的并发、Celery 队列、Redis 取消与远程性能节点；新增取消接口在服务器返回 404。

## 审查修复：本地异常退出恢复

- 性能运行恢复覆盖 `cancelling`，将其收敛为 `cancelled`；执行返回后仍处于停止中的状态也按未完成处理。
- 根运行按 `id + created_at` 校验身份；已保存终态的运行保留结果，独立清理遗留执行/设备租约。缺少身份或身份不匹配的旧队列记录不清理当前运行。
- 参数化及多设备用例按 `test_runs.parent_run_id` 递归恢复；套件/计划的终态子运行也参与租约清理。增加已访问记录，避免循环关联重复递归。
- 释放自己拥有的 Android 设备租约后，只有设备仍为 `busy` 且没有剩余租约时才恢复 `online`；离线状态和其他任务的租约保持不变。
- 本次修复未新增或运行自动化测试；检查范围为 Ruff 和 mypy。异常退出、停止中重启及真机状态仍需业务验收。

## Hermes 页面整理

- 对话作为主要内容，质量与失败任务放在固定宽度侧栏；窄屏改为单列。
- 对话筛选默认收起，保留来源筛选数量和历史预算摘要；回答质量指标移到页面底部，按需展开。
- 快捷提问改为轻量按钮，工具调用记录默认折叠，缩短对话区以便更快找到输入框；移除重复的英文装饰标题。
- 此次调整仅涉及展示，不改变会话、检索、反馈和计划草稿的数据逻辑。
- 输入区改为多行，默认 3 行，自动增高到 10 行；Enter 换行，Ctrl/Command + Enter 发送。中文输入法组合输入、空白内容和忙碌状态不会触发快捷发送。

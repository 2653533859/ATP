## 1. 版本概述 (Executive Summary)

ATP v2.9.0 是自动化测试平台迈向**全栈前端体验革新、弱网仿真可视化、AI 智能探索控制台与企业级 FinOps 成本中心**的里程碑正式发布版本。

本版本紧密承接 v2.8.0 沉淀的后端核心算法与微服务架构，历经 4 大阶段共 12 项重大交互组件与控制台落地，达成了：
1. **弱网与网络仿真交互工作台 (Phase 1)**：在设备中心与远程工具箱提供 7 类弱网预设档案参数试算抽屉、标准 HAR 1.2 抓包流量耗时瀑布流与慢请求 Top 5 诊断、以及五维抗弱网韧性雷达图与在线故障模拟评估；
2. **AI 自主探索与用例生成可视化控制台 (Phase 2)**：在 AI 工作台构建完整的页面有限状态机（FSM）力导向拓扑关系图、置换不变状态指纹查看器、高噪事件流去噪折叠轨迹与 TestCase 一键合成持久化面板，以及假死崩溃与死循环振荡 4 大健康探针熔断告警卡片；
3. **持续性能混沌与容量预测图表视图 (Phase 3)**：在压测中心无缝集成 Baseline 漂移偏离度监控卡片与智能一键晋升、双 Y 轴三段式混沌故障注入时间线与持续健康窗口自愈 RTO 秒级测定，以及并发-吞吐量线性拟合与并发-延迟二次多项式拟合双回归容量预测图及饱和拐点（Knee Point）；
4. **多租户资源配额与企业 FinOps 成本中心 (Phase 4)**：在系统配置中心提供项目级并发与每日时长实时水线进度条、配额参数调优与僵尸任务一键收割日志，MinIO 资产生命周期分级过期预览与物理安全清理抽屉，以及全新的企业级 FinOps 成本分摊看板（支持单价微调、多租户透视表、费用占比环形图及带 UTF-8 BOM 头的 Excel 兼容 CSV 下载）。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：弱网与网络仿真交互工作台 (Network Emulation Studio)

- **F1.1 弱网仿真档案管理与参数试算抽屉 (`NetworkProfileDrawer.vue`)**：
  - 展示 2G GPRS、2G EDGE、3G HSPA、4G LTE、高延迟、高丢包与离线断网 7 类预设档案；
  - 交互式试算器支持自定义数据包大小（Bytes），即时计算预估传输延迟、随机丢包判定，并实时预览生成的 Web CDP 与 Android ADB `tc netem` 注入指令；
  - 在移动设备管理页（`DeviceList.vue`）操作栏提供全局入口。
- **F1.2 HAR 抓包流量瀑布流与慢请求 Top5 诊断卡片 (`HarTrafficViewer.vue`)**：
  - 联动后端 `/network-profiles/parse-har`，全景呈现总请求数、请求成功率、平均响应时间与总传输流量；
  - 自动提炼响应最慢的前 5 个慢接口卡片，并绘制动态耗时渐变瀑布流比例条；
  - 支持按异常状态过滤与 URL 关键字模糊搜索，在系统远程工具箱提供入口并异步懒加载。
- **F1.3 弱网抗性评分雷达图与故障注入评估面板 (`NetworkResilienceRadar.vue`)**：
  - 基于 ECharts 绘制响应速度、成功率、重试适应力、超时防抖与综合韧性五维评估雷达图，直观展示 Grade A/B/C/D 徽标；
  - 在线模拟目标接口在 DNS 劫持、TCP 连接中断、网关超时或 503/502 故障策略下的阻断/降级行为；
  - 嵌入弱网仿真抽屉 Tab 形成闭环网络演练工作台。

---

### Phase 2：AI 自主探索与用例生成可视化控制台 (Autonomous Exploration Console)

- **F2.1 页面状态树（FSM）拓扑与状态指纹视图 (`ExplorationGraphViewer.vue`)**：
  - 后端升级 `/exploration/sessions/{id}` 返回完整的 `nodes` 与 `links`；
  - 前端基于 ECharts Graph 渲染力导向拓扑关系图，节点展示 16 位置换不变指纹哈希（State Hash），有向连线标注操作转移；
  - 右侧抽屉即时查看选中页面的动作槽（Candidate Actions）与探索进度，支持载入 live session 或典型电商链路示例。
- **F2.2 探索事件流实时轨迹与一键生成 TestCase (`ExplorationTraceSynthesizer.vue`)**：
  - 直观对比原始高噪事件流与提炼步骤清单，计算去噪压缩率（如 60%）；
  - 自动生成终态文本断言步骤（`assert_text`）与关键交互标记；
  - 支持配置用例归属模块与执行终端平台，一键原子落库保存为平台标准用例资产。
- **F2.3 异常假死与死循环振荡熔断告警卡片 (`ExplorationCircuitBreakerCard.vue`)**：
  - 实时监控连续 0 元素黑屏、驱动连续失联、乒乓往复振荡与步数超限 4 大安全探针进度条；
  - 熔断时自动弹出醒目红底警示横幅与事故终止快照（Exploration Abort Snapshot），给出具体的故障原因与修复指南；
  - 内置「模拟黑屏崩溃」、「模拟死循环」、「模拟驱动失联」3 种异常演练触发器。

---

### Phase 3：持续性能混沌与容量预测图表视图 (Performance Chaos & Capacity Forecaster)

- **F3.1 基线自动打标、漂移偏离度比对与指标告警 (`BaselineDriftMonitor.vue`)**：
  - 联动 `/performance/runs/{id}/drift-alert` 与 `/performance/tests/{id}/align-baseline`；
  - 呈现吞吐量（RPS）、响应延迟（P95）与错误率三核心指标偏离对比卡片，智能评定 None/Warning/Critical 严重度；
  - 智能评估更优候选并支持一键原子晋升更新基准线，集成至压测中心操作区。
- **F3.2 压力下混沌故障注入时间线与自愈 RTO 测定曲线 (`ChaosRtoTimeline.vue`)**：
  - 双 Y 轴呈现吞吐量平滑折线与 P95 响应延迟；
  - `markArea` 浅红渐变高亮故障注入区间，`markLine` 绿色虚线与标注点精准指引**自愈确认点与 RTO 间隔**（秒级精度）；
  - 突出呈现 Grade A-F 韧性等级徽章与防抖持续健康时间窗口指标。
- **F3.3 回归容量预测、饱和拐点与并发上限预测图 (`CapacityRegressionChart.vue`)**：
  - 基于实测散点，双轴绘制并发-吞吐量一阶线性扩展回归虚线与并发-延迟二阶多项式恶化曲线；
  - 标红指示 SLA 延迟红线（如 $P95 = 500\text{ms}$），反解展示最大安全承载并发上限（VU），紫色高亮锁定饱和拐点（Knee Point）；
  - 配套多轮横向横截面对比矩阵表格，展示每轮测试的单并发扩展效能比（RPS/VU）。

---

### Phase 4：多租户资源配额与企业 FinOps 成本中心 (Multi-Tenant Quota & FinOps Cost Center)

- **F4.1 项目资源配额配置与并发/时长硬限制仪表板 (`ProjectQuotaDashboard.vue`)**：
  - 实时监控并发运行水线与今日累计时长额度消耗；
  - 管理员可视化调优最大并发数（1-100）、每日时长上限、单任务硬超时与超额策略（立即拒绝 / 自动排队）；
  - 提供超时僵尸长任务一键强制收割日志面板，挂载至系统配置中心。
- **F4.2 测试资产 MinIO 生命周期与自动清理交互抽屉 (`AssetStorageLifecycleDrawer.vue`)**：
  - 支持视频（7d）、截图（14d）、Traces（14d）、报告（30d）与日志（30d）多分类资产过期预览（Dry-Run）；
  - 呈现各分类预计释放的存储空间大小（MB/GB）与抽样文件清单，执行后自动同步收敛数据库孤儿引用，杜绝 404 死链。
- **F4.3 企业级 FinOps 成本分摊看板与 CSV 导出 (`FinOpsCostCenterView.vue`)**：
  - 挂载路由 `/system/finops`，展示平台总资源开销（¥）、计算开销与累计核时、存储开销与占用 GB；
  - 费用分摊占比环形图透视各项目费用权重；
  - 多租户成本透视表内置智能降本建议提示，支持一键下载带 UTF-8 BOM 头的 Excel 兼容 CSV 财务对账报表。

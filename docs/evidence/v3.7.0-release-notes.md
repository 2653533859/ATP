# ATP v3.7.0 官方版本发布说明与全量验收公告 (2026-10-16)

## 概述与版本发布声明

**ATP (Automated Testing Platform) v3.7.0 正式发布！**
本里程碑聚焦于 **「代码变更影响面分析、精准测试推荐选择与变异质量门禁前端控制台」**，全面对齐与承接后端 v3.6.0 的代码语义分析、风险评估与变异测试能力，为研发与测试工程师提供端到端高可用、现代 SaaS 科技质感的交互控制台。

本版本历经 4 大阶段（Phase 1 ~ Phase 4），共计完成 **12 大核心功能模块** 的全量交付、独立单元测试与生产构建验证，全要素质量门禁指标达成率 **100%**。

## 一、 v3.7.0 核心功能与交付矩阵

### Phase 1: 代码变更差异语法树与精准测试推荐工作台控制台 (100% 闭环)
1. **UI1.1 Git Diff 代码变更语法高亮与符号路由映射抽屉 (`GitDiffAstViewerDrawer.vue`)**:
   - 呈现 Unified Diff 代码高亮预览、增删改统计 KPI 卡片；
   - 提取 AST 变更类/函数/方法与受影响 API 路由端点双栏联动，集成至 `ApiWorkbenchView`。
2. **UI1.2 代码符号与自动化测试用例双向血缘图谱视图 (`CodeToTestDependencyGraphView.vue`)**:
   - 采用 ECharts 力导向拓扑网络（Force-Directed Graph），呈现「源文件 → 类/函数 → API 路由端点 → 自动化测试用例」四级依赖；
   - 节点多维属性下钻面板与用例血缘反向注册。
3. **UI1.3 精准测试集推荐裁剪率与一键回归执行卡片 (`SmartTestSelectionWorkbenchCard.vue`)**:
   - 策略自由切换（极小推荐 / 均衡推荐 / 深度全量），呈现 80%+ 冗余用例裁剪率；
   - 推荐用例置信度卡片清单与一键回归执行，集成至 `ApiWorkbenchView`。

### Phase 2: 动态切片并发看板与代码变更风险全景面板 (100% 闭环)
4. **UI2.1 LPT 贪心装箱并发切片甘特图与负载均衡卡片 (`DynamicTestShardingGanttCard.vue`)**:
   - 可视化展示 N 个 Worker 容器并发分片用例装箱甘特图，消除执行木桶短板；
   - 理论加速比 KPI（如 3.66x）与耗时方差极小化呈现，集成至 `AppWorkbenchView`。
5. **UI2.2 代码变更规模/圈复杂度与核心敏感度三维风险雷达大盘 (`ChangeRiskRadarDashboard.vue`)**:
   - 量化代码体量 (30%)、圈复杂度增量 (35%) 与核心资产涉敏度 (35%) 三维风险；
   - ECharts 三维雷达图对比 25 分安全基线，CRITICAL ~ LOW 四级准入动作建议大横幅。
6. **UI2.3 CI 选定测试集高频抖动 Flaky 用例自适应抑制隔离抽屉 (`FlakyQuarantineManagementDrawer.vue`)**:
   - 抖动指数彩色进度条展示、5 大 KPI 收益看板；
   - 三态自适应抑制表格（正常放行 / 自动退避重试 / 隔离观察队列）与治理白名单工单覆盖录入，集成至 `AppWorkbenchView`。

### Phase 3: 代码变异测试执行与断言盲区热力工作台 (100% 闭环)
7. **UI3.1 一阶语法变异算子注入生成与变异代码对比弹窗 (`CodeMutationOperatorGeneratorModal.vue`)**:
   - 5 大一阶语法算子选择（ROR 关系、LCR 逻辑、AOR 算术、RVO 返回值、BVO 边界值）；
   - 4 大 KPI 卡片、单变异体独立隔离列表与红绿底行级双栏代码比对，集成至 `ApiWorkbenchView`。
8. **UI3.2 变异体沙箱执行实时进度与 Killed/Survived 监控抽屉 (`MutationExecutionLiveMonitorDrawer.vue`)**:
   - 变异体沙箱执行实时状态流监控，精准展示 Killed（绿标）与 Survived（红标）；
   - 定位具体击毙变异体的用例名称及捕获的 `AssertionError`，集成至 `ApiWorkbenchView`。
9. **UI3.3 变异得分 (Mutation Score) 与断言盲区热力报告页面 (`MutationScoreHeatmapReportView.vue`)**:
   - 综合变异得分圆环（0~100%）与四级充分性裁决（EXCELLENT ~ WEAK）；
   - 五大算子击毙率雷达图对比 85% 卓越基线，断言盲区代码行级热力清单与针对性断言修复指引。

### Phase 4: CI/CD PR 全要素质量门禁与 Reviewer 机器人控制中心 (100% 闭环)
10. **UI4.1 PR 代码变更全要素质量门禁合并准入仲裁卡片 (`PrQualityGatekeeperDashboardCard.vue`)**:
    - 聚合单测通过率（100%）、代码变异得分（≥70%）与极高危变更双人审批三项红线；
    - 呈现三态裁决徽章（APPROVED / BLOCKED / CONDITIONAL）、多维规则裁决矩阵表格与整改行动项清单，集成至 `ApiWorkbenchView`。
11. **UI4.2 GitHub / GitLab 交互式 Reviewer 评论卡片预览与广播抽屉 (`PrCommentBotPreviewDrawer.vue`)**:
    - 支持 GitHub / GitLab / Gitea 多平台切换；
    - 所见即所得双栏实时渲染（Markdown 源码编辑 + Git PR 评论气泡高保真仿真渲染）与一键 Webhook 广播，集成至 `ApiWorkbenchView`。
12. **UI4.3 CI/CD 流水线 Checkpoint 检查点全景监控看板页面 (`CiPipelineCheckpointMonitorView.vue`)**:
    - 端到端四阶段流水线执行状态全景拓扑图；
    - 显式展示 Exit Code 0（通过）、1（阻断）、2（告警）；
    - 高对比度终端控制台日志输出窗口，支持一键复制与自动滚屏。

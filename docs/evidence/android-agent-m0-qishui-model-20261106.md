# Android Agent M0：汽水音乐与视觉模型首次实测

日期：2026-11-06。工作区原型验证，未部署、未完成 M0 验收。用户指定汽水音乐并授权向其提供的模型接口发送截图；密钥只用于当前调用进程，不进入源码、报告或本地数据库配置。

后续重连、搜索和单步回放结果见[重连搜索验证](android-agent-m0-qishui-search-20261106.md)。下文断线状态保留为本轮历史快照。

## 模型侧证据

- `/models` 接口返回 200 和 8 个模型 ID；这只证明接口可访问，不证明所有模型均支持视觉。
- 选择接口实际返回的 `gemini-3-flash` 验证。新增 `model_probe.py`，复用 ATP `LLMRequest/call_llm`；返回严格校验的候选动作、耗时和数值用量，不执行动作或存储原始模型响应。
- `scripts/android-agent-model-probe.py` 生成两张红蓝按钮测试图，第二张交换颜色位置。两次模型返回均通过 JSON 协议和当前上下文校验，蓝色按钮目标均正确；耗时 5983 / 4811 ms，总 token 分别为 3130 / 3129。仅为两次合成图探测，不代表实际 App 成功率。
- 使用用户授权的汽水音乐实际截图，附带“UI 树不可用、设备已断开”的观察信息。模型返回 `request_help/cannot_progress`，没有编造节点；耗时 6156 ms，总 token 3141。未执行模型动作，不计自主探索成功。
- 脱敏结果：`.local-run/android-agent-model-probe-gemini-20261106.json`、`.local-run/android-agent-model-qishui-20261106.json`。原始手机截图仅位于忽略目录中，不纳入提交。

复跑合成测试需要在调用进程环境中设置 `ATP_AGENT_PROBE_API_KEY`，通过 `--endpoint`、`--model` 指定已授权接口与模型；`--output` 必须使用新文件。脚本不接受命令行密钥参数，不读取手机画面。

## 设备侧证据

- 曾连接 1 台 OPPO R11，Android 9，1080×1920；汽水音乐包名 `com.luna.music`，版本 21.5.0。设备标识不写入本报告。
- ADB 启动 App 成功，取得真实截图。初次 UI 采集返回 `null root node`；随后可取得一份 47 节点的 XML，但会员弹窗的关闭控件未以可用节点暴露。
- 基于已观察画面人工辅助关闭会员弹窗；这不是 Agent 自主动作，不计作自动化成功。未点击购买、收藏、关注或账号设置。
- 播放页面动态变化，后续 UIAutomator 返回 `ERROR: could not get idle state.`，虽然进程退出码为 0。新增 `parse_dump_output`，将上述情况分类为失败，避免退出码假阳性。
- App 进入播放页后出现自动播放。尝试通过已观察到的暂停按钮停止播放，随后 ADB 连接中断；不能确认最后一次点击的结果，没有重复发送该切换操作。
- 最后一次复核 ADB 设备列表为空。截图/UI 树采集失败后停止设备操作；待重新连接，必须重新观察页面再继续。

## 代码与测试

- 动作上下文新增显式 `device_online` 和 `observation_available` 条件；离线或无有效观察时拒绝操作与 finish，只允许求助候选。它仍不是完整的生产鉴权、租约与执行门禁。
- 增加 UIAutomator 零退出码错误输出、离线完成误判和模型传输异常脱敏的回归覆盖。
- 相关三个测试文件合并运行：**60 passed**；Ruff、mypy（4 个服务文件）及差异检查通过。未进行全量测试。

## 结论和剩余项

已验证真实模型接口、有限合成视觉定位、真实 App 截图、部分 UI 树采集和断线后的安全停止。没有完成“搜索晴天”、中文输入、结构化业务断言或独立回放；也未完成持久协调器、设备互斥、第二个测试 App 和模拟器矩阵。因此 M0 保持进行中。

下一步：恢复稳定 ADB → 确认当前页面/播放状态 → 采集稳定观察 → 验证搜索定位与中文输入。无法获得控件树时先记录降级限制，不让原型盲目点击模型给出的坐标。App 的授权截图范围仍遵循用户本次授权，账号/支付等无关页面不纳入模型验证。

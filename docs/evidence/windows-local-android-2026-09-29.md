# Windows 本地 Android 阶段证据（2026-09-29）

## 范围

本阶段只扩展 Windows 本地模式的 Android 能力：APP 工作台、本机 ADB 扫描与设备控制、APK、Android 用例及专项任务手动执行。服务器模式继续走原有 Android Worker；本地 iOS、定时调度和分布式 Worker 不在范围内。

## 已验证

- `adb devices -l` 能执行，当前返回空设备列表。APP 工作台手动扫描显示“设备扫描完成，共 0 台”，无设备时运行入口保持禁用或返回明确错误。
- `8001/health` 返回 `ok`；运行身份返回 `local/sqlite/filesystem`；本地静态页面的 APP 自动化入口、SQLite 队列标识和无设备引导在浏览器中可见。
- Android 用例投递复用本地 SQLite 队列；专项任务本地投递、停止信号、投递失败状态和运行中断恢复通过定向回归。中断恢复会释放对应设备与执行租约，不自动重放可能有副作用的运行。
- 后端非集成全量和 82% 覆盖率门槛、前端本地模式静态构建、定向前端测试、Ruff、mypy 均通过。最终非集成后端回归为 **2789 passed、2 skipped，覆盖率 82.04%**；定向后端回归 66 passed，前端定向 12 passed。

## 开放项

- 当前无已连接 Android 设备，也无本地 APK 样本。本机真实脚本、APK 安装、性能/稳定性/流畅度三类专项、截图与报告、运行中停止和设备断连恢复尚未验收。
- `127.0.0.1:5173` 服务器页面不可达，正式服务器 Android Worker、Celery/Redis/MinIO 和双模式同时登录的现场回归尚未完成。代码回归不能代替这些现场证据。

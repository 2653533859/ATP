# Hermes 目标环境角色与审计验收计划（运行前冻结）

## 范围

使用现有管理员和 `atp-slo-canary` 验收账号，经正式 API 创建两个临时空白项目 A、B；只给验收账号分配 A 的项目 `viewer`，B 不分配成员。A、B 各创建一条互相矛盾且带唯一标记的临时需求。A 绑定现有已启用模型配置，B 不必调用模型。凭据只从服务器受限文件读取，不进入脚本参数、报告或仓库。验收后移除 A 的临时成员关系，再删除 A、B 并回查；原项目 77 的模型绑定与资产保持不变。

## 冻结判据

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| P01 | 管理员和验收账号登录，管理员读取 A/B，验收账号读取 A | 全部 HTTP 200；验收账号对 A 为 `viewer` |
| P02 | 验收账号在 A 提问唯一标记 | HTTP 200；来源只归属 A，回答若为模型生成必须引用有效来源；验收账号会话可读取 |
| P03 | 验收账号对 A 执行 `failed_tasks` 只读工具 | HTTP 200；状态为 `ok` 或 `empty`，新增 1 条 `hermes_read_tool` 审计，审计归属 A/该用户 |
| P04 | 验收账号在 A 创建模块与 Hermes 计划草稿 | 两项均 HTTP 403，且 `access_denied` 审计分别留在 A |
| P05 | 验收账号读取 B 项目详情、Hermes 查询、编排、只读工具及会话列表 | 五项均 HTTP 403；B 的 `access_denied` 审计记录该用户；不能返回 B 来源或工具证据 |
| P06 | 管理员尝试对验收账号会话提交反馈；验收账号列出自己的会话并尝试评价管理员会话 | 两次跨用户反馈均 HTTP 404；会话列表 HTTP 200 且不含其他用户会话 |
| P07 | 验收账号对自己的助手消息提交一次反馈并同值重试 | 两次 HTTP 200；当前会话 helpful 计数仅增加一次 |
| P08 | 移除 A 成员后，验收账号再次查询 A | HTTP 403，审计增加；管理员仍可读取 A |
| P09 | 删除 A/B，回查项目和临时需求；读取原项目 77 | 临时资源均 HTTP 404；项目 77 HTTP 200，模型绑定与运行前相同 |

全部九项通过且 P04/P05/P06 无越权、P03/P04/P05/P08 审计归属正确才算通过。任一缺少审计、跨项目来源、跨用户会话访问、凭据回显或清理失败均阻塞本次角色与审计结论。若模型未生成有效回答，P02 不算通过；不得以 HTTP 200 代替真实模型或引用验收。报告只保存状态码、来源项目 ID、消息/审计数量与判定，不保存回答、需求正文、Token、Cookie、密码或供应商密钥。

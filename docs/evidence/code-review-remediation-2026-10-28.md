# 2026-10-28 代码审查修复

本次对应八项审查发现；不运行生产迁移、不改变远端部署。

- API Key：有效角色取用户与密钥的较低权限，不修改数据库中的用户角色；禁止受限身份签发更高角色的密钥。项目或环境限定 Key 在通用接口返回 403，直到接口具备显式范围授权契约。现有使用此类 Key 的调用方需要调整，不能将其视作已支持的范围访问。
- Device Agent：JWT 必须为 access 类型；接入时重新查询用户，拒绝不存在、禁用及非 admin/engineer 账户。无效令牌不再回退为本地身份。
- 冻结入口：为 pytest、Locust 和 pip 提供受控模块分派；包含脚本依赖目录的 PYTHONPATH 在冻结子进程中显式恢复。构建脚本收集三个模块和 pytest 插件。
- 云同步：套件、计划从 result_summary 读取统计，移动专项使用 app_package，避免查询不存在的列而漏入同步队列。
- 历史迁移：导入前检查全部实体 ID，任何碰撞或源数据重复 ID 都中止事务。保留源 ID 是为了保持附件路径有效；此脚本不再允许以 ID 相同为由跳过实体，也不支持向有碰撞的目标重复导入。需要合并已有数据库时应另行提供实体和对象路径的完整映射迁移。
- 空库管理员使用正常 PBKDF2 哈希；历史时间、环境、参数化字段保留，父运行关系在全部运行插入后补齐，并显式保留 updated_at。
- 远程通道为 8 MiB 正文的 Base64 编码及消息头保留有界接收空间，已有 800 KiB 真实本地 WebSocket 回归用例。

回归测试位于 `backend/tests/services/test_review_remediation.py`，测试迁移函数时只加载离线函数，使用内存 SQLite，避免加载脚本启动配置或连接生产源。

## 1. 版本概述 (Executive Summary)

ATP v3.2.0 是自动化测试平台迈向**高可用微服务集群协同调度、全景测试资产依赖图谱、多协议动态沙箱编排与 CI/CD 质量准入门禁中心**的重大里程碑正式发布版本。

本版本紧密围绕集群高可用性、资产治理与质量门禁，历经 4 大核心技术阶段共 12 项重大子系统级技术演进，已实现 100% 全量大闭环交付：
1. **跨节点 Worker 集群自适应负载与动态弹性调度 (Phase 1)**：落地 Worker 节点多维加权负载评分（并发/CPU/内存）与最优调度算法、P0/P1 高优先级自适应弹性抢占插队与任务挂起唤醒机制，以及心跳超时自动收割与孤儿任务故障转移重试（Failover Recovery）；
2. **全域测试资产依赖拓扑与变更影响面智能分析 (Phase 2)**：构建涵盖 Plan-Suite-Case-API-Dataset 七维有向图谱与正反双向索引引擎、未引用孤儿用例与废弃数据集自动探测、接口契约变更影响面逆向推导与破坏性定级，以及变更影响用例自动化精准回归套件合成与 P0 调度触发；
3. **多协议测试执行动态沙箱与隔离环境编排 (Phase 3)**：构建 20000-29999 端口动态无冲突套接字探测分配器、支持 HTTP/gRPC/WebSocket 协议的瞬时仿真沙箱与 TTL 自动回收、跨协议会话数据透传与双向上下文共享总线，以及影子网络流量镜像与敏感外发写操作副作用拦截隔离；
4. **企业级测试质量度量大盘与质量门禁策略中心 (Phase 4)**：落地覆盖自动化覆盖度（30%）、缺陷逃逸率（25%）、执行稳定性（25%）与 MTTR（20%）的四维加权质量健康度量引擎、支持全算子比较与阻塞卡点拦截（exit_code=1）的 CI/CD 质量门禁引擎，以及带有不可伪造 HMAC-SHA256 数字安全印章的正式发版准入合格证书。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：跨节点 Worker 集群自适应负载与动态弹性调度 (Dynamic Cluster Autoscaling & Adaptive Scheduling)

- **C1.1 跨节点 Worker 节点动态负载监控与容量评分算法 (`cluster_load_balancer`)**：
  - 实时采集 Worker 节点并发占用率、CPU 使用率与内存使用率；
  - 多维加权复合负载评分公式：$0.50 \times \text{并发} + 0.30 \times \text{CPU} + 0.20 \times \text{内存}$；
  - 节点健康分级五层梯队（`HEALTHY_IDLE`、`MODERATE_LOAD`、`HEAVY_LOAD`、`OVERLOADED`、`OFFLINE`）；
  - 全局自适应选举可用容量最高的最优 Worker 节点。
- **C1.2 基于执行队列水位与优先级自适应弹性抢占调度器 (`adaptive_queue_preemptor`)**：
  - P0（紧急冒烟）、P1（核心自动化）、P2（常规回归）、P3（批处理归档）四级优先级梯队；
  - 集群槽位满载时，P0 紧急任务自动对运行中的 P3/P2 任务执行弹性挂起抢占（`suspended`）；
  - 任务执行完毕后优先唤醒被挂起任务，结合集群吞吐量动态精准测算排队预计等待时长（ETA）。
- **C1.3 节点失联与心跳超时自动化任务故障转移与断点重试 (`worker_failover_recovery`)**：
  - 心跳超时（默认 30s）未上报节点自动判定失联并标记 `offline`；
  - 自动抢救悬挂的 `running` 孤儿任务，递增重试计数并重新分发到存活节点继续执行；
  - 超过最大重试限制（默认 3 次）安全标记为 `aborted` 终止态。

### Phase 2：全域测试资产依赖拓扑与变更影响面智能分析 (Global Asset Dependency & Impact Analysis)

- **C2.1 测试资产全景引用拓扑图谱与反向索引引擎 (`asset_graph_indexer`)**：
  - 建模 Plan-Suite-Case-API-Dataset-Device-Env 统一资产节点与 5 大关联关系；
  - 正向依赖索引（向下查依赖）与反向消费索引（向上查血缘影响）；
  - 自动探测未被任何套件或计划引用的孤儿测试用例与废弃冗余数据集。
- **C2.2 接口契约变更影响面逆向推导与受影响用例标记 (`contract_change_impact_analyzer`)**：
  - 对比新旧 OpenAPI / JSON Schema 契约差异，精准提取 `breaking_changes` 与 `warnings`；
  - 结合图谱反向索引自动推导出受波及的用例清单，标注受影响步骤号与破坏性危险等级。
- **C2.3 变更影响用例自动化精准回归套件合成与触发 (`targeted_regression_trigger`)**：
  - 自动对受波及用例去重、优先级排序并合成结构化精准回归测试套件；
  - 破坏性契约变更自动将执行任务提权至 `P0`，触发自适应弹性抢占调度；
  - 支持原子持久化保存为平台 `TestSuite` 资产记录。

### Phase 3：多协议测试执行动态沙箱与隔离环境编排 (Multi-Protocol Sandbox Orchestration)

- **C3.1 瞬时轻量级仿真沙箱与动态端口生命周期调度 (`ephemeral_sandbox_manager`)**：
  - 管理 20000-29999 瞬时端口区间，执行真实套接字绑定探测（`SO_REUSEADDR`）防止端口冲突；
  - 原生支持 HTTP、gRPC 与 WebSocket 多协议仿真基地址自动组装；
  - 严格管理沙箱生命周期 TTL（默认 300s），全自动定期巡检并收割过期沙箱。
- **C3.2 跨协议数据透传与会话级上下文共享总线 (`cross_protocol_session_bus`)**：
  - 建立会话级共享变量字典，打通跨协议数据总线；
  - 自动将 HTTP 认证头标与链路追踪 ID 透传至 gRPC Metadata 和 WebSocket 握手参数中；
  - 接收并解析 WebSocket 异步下发的 JSON 帧消息，提取关键字段回流至总线变量；
  - 通用递归模板插值引擎支持在各协议报文与 URL 中解析 `{{variable}}`。
- **C3.3 沙箱网络流量镜像与回放实时隔离检测 (`sandbox_traffic_mirror`)**：
  - 支持将业务流量按抽样比例克隆镜像（Shadow Traffic）至瞬时隔离沙箱；
  - 严格审查并拦截沙箱外发写操作（POST / PUT / DELETE / PATCH），就地返回隔离仿真响应；
  - 杜绝向第三方发起真实扣款、短信轰炸或通知打扰，提供零泄露安全验证凭证。

### Phase 4：企业级测试质量度量大盘与质量门禁策略中心 (Quality Metrics & Governance Gate Center)

- **C4.1 全生命周期测试质量度量多维评分大盘 (`quality_metrics_engine`)**：
  - 涵盖自动化用例覆盖度（30%）、缺陷逃逸率（25%）、执行稳定性（25%）与 MTTR（20%）四大维度；
  - 计算 0.0 ~ 100.0 项目级加权总分，划分 Grade A-F 评级与发版准入状态（`APPROVED` / `WARNING` / `BLOCKED`）；
  - 自动生成具体的风险警告与质量流程改进建议。
- **C4.2 CI/CD 流水线智能质量门禁规则判定引擎 (`quality_gate_engine`)**：
  - 支持配置灵活指标比较规则（算子 `gte`、`lte`、`eq`、`gt`、`lt`）；
  - 预设生产发版准入门禁（`gate_prod_release`）与 PR 合并门禁（`gate_pr_check`）；
  - 阻塞卡点规则未达标时直接返回 `exit_code = 1` 阻断流水线非法发布。
- **C4.3 自动化发布准入认证与防伪合格证书生成 (`release_readiness_certification`)**：
  - 自动汇总质量健康四维得分与门禁决策判定，生成唯一的企业级发版证书编号；
  - 采用密码学 HMAC-SHA256 算法生成防伪数字印章签名，封存发版版本号、Commit SHA 与通过决议；
  - 提供常数时间数字验签比对引擎，任何离线篡改均被即刻识破并报警。

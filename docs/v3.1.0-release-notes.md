## 1. 版本概述 (Executive Summary)

ATP v3.1.0 是自动化测试平台继 v3.0.0 完成核心引擎架构演进后，全面迈向**微服务流量录制工作台、真机回放音画排障器、网关混沌拓扑控制台与企业级合规安全中枢前端全量落地**的重磅正式发布版本。

本版本历经 4 大核心交互阶段，共计 12 项重大组件、视图与抽屉落地，已实现 100% 全量大闭环交付：
1. **微服务流量录制与用例逆向生成工作台 (Phase 1)**：在接口工作台落地流量录制会话管理抽屉、静音清洗与凭据脱敏流水展示，动态参数跨步依赖推导（`{{variable}}`）对比抽屉，以及三步走智能断言生成与 TestCase/TestSuite 一键持久化落库向导；
2. **移动端真机回放与视频关键帧逐帧排障器 (Phase 2)**：在移动工作台落地真机回放动作编排执行抽屉与运行时上下文（`{{var}}`）注入、Tier 1~3 启发相似度与 OCR 物理边界包围盒及准星画布比对器，以及 MP4 录屏毫秒级彩色书签时间轴与异常高亮播放器；
3. **微服务网关混沌演练与爆炸半径控制台 (Phase 3)**：在压测中心落地网关 503/熔断/延迟/畸形报文 4 大故障动作规则卡片与动态流量抽样滑块、ECharts 力导向微服务依赖拓扑图与 Emergency Abort 红色熔断告警，以及全链路高可用 SLA 达成度跌幅与自愈 RTO 评级报告看板；
4. **企业级 OIDC/SSO 与不可篡改审计安全中心 (Phase 4)**：在配置中心落地 Keycloak/Okta/ADFS 身份源配置与防重放单点登录卡片、细粒度 RBAC 策略决策点（PDP）模拟器与 Anti-IDOR 跨项目越权诊断抽屉，以及类区块链 SHA-256 审计日志哈希指针链条自检、模拟篡改定位与带数字签名的正式合规报表导出。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：微服务流量录制与用例逆向生成工作台 (Traffic Ingestion & Reverse Synthesis Studio)

- **UI1.1 微服务流量录制会话管理与实时抓包面板 (`TrafficRecordingDrawer.vue`)**：
  - 目标微服务 Base URL 配置、一键静音清洗开关（自动剥离静态资源与 `/healthz` 探测）；
  - 录制状态呼吸点（Live Pulse Dot）、已捕获请求数统计、噪声过滤清洗率（%）；
  - 请求流水列表展现 Method 标签（GET 绿、POST 蓝、DELETE 红）、状态码与耗时分布，敏感凭据（`Authorization`、`Cookie`）严格脱敏显示并可展开 JSON 报文；
  - 挂载至 API 测试工作台（`ApiWorkbenchView.vue`）。
- **UI1.2 动态参数提取与上下文占位符规则配置抽屉 (`DynamicParamExtractorDrawer.vue`)**：
  - 展示跨步骤参数流转链路表格（步骤 #i 生产 $\rightarrow$ 步骤 #j 消费）；
  - 自动识别并高亮推导出的占位符变量（如 `{{order_id}}`）与提取表达式（如 `$.order_id`）；
  - 提供参数化前后请求 JSON 报文对比预览与生成的 `Extractions` 规则清单。
- **UI1.3 录制流量一键逆向合成用例与套件向导弹窗 (`TrafficToCaseWizard.vue`)**：
  - 三步走向导支持选择单用例（TestCase）或测试套件（TestSuite）；
  - 自动生成三重断言规则（HTTP 状态码强校验、响应体业务字段 `code`/`success` JSONPath 断言、单步响应时延 SLA 阈值红线）；
  - 支持数据库原子持久化落库（`persist: true`），生成正式资产 ID（如 `#201`）并提供多步骤表格预览。

### Phase 2：移动端真机回放与视频关键帧逐帧排障器 (Mobile Playback & Video Frame Inspector)

- **UI2.1 真机回放动作编排执行抽屉与变量上下文配置 (`DevicePlaybackDrawer.vue`)**：
  - 支持 Android / iOS 双平台选择、设备序列号/UDID 校验、目标应用 Package/Bundle ID 配置；
  - 一键载入包含点击（`click`）、输入（`input_text`）、滑动（`swipe`）、断言（`assert_text`）的标准四步动作序列；
  - 提供运行时 JSON 变量上下文编辑器（支持动态注入 `{{keyword}}` 等运行时参数）；
  - 实时表格呈现动作步骤、执行参数、耗时以及状态（`passed` 绿、`failed` 红、`healed` 橙）。
- **UI2.2 视觉/DOM 混合自愈与 OCR 物理边界比对器 (`VisualSelfHealingInspector.vue`)**：
  - 动态展示自愈策略标签（Tier 1 绝对 DOM、Tier 2 无障碍树启发、Tier 3 视觉 OCR 自愈）、自愈状态与置信度得分（如 95%）；
  - 移动端屏幕模拟画布动态标注 OCR 物理包围盒（黄色虚线框）与物理点击中心十字准星红点；
  - 展示三层级自愈决策链条时间线（Tier 1~3）。
- **UI2.3 MP4 录屏毫秒级时间线对齐与异常高亮播放器 (`PlaybackKeyframeTimeline.vue`)**：
  - 呈现视频总时长、FPS 帧率、总视频帧数、回放通过率与总体健康状态徽标；
  - 交互式深色时间轴轨道动态渲染多色彩色书签引脚（正常步骤绿色、自愈关键帧橙色、失败现场红色）；
  - 点击任意书签或按钮，即时高精度跳转当前位点秒数（如 `0.25 秒`）并同步指示绝对视频帧号（如 `#7 帧`）；
  - 呈现蓝色播放头准星线与展开的失败排障信息。

### Phase 3：微服务网关混沌演练与爆炸半径控制台 (Mesh Chaos & Blast Radius Studio)

- **UI3.1 微服务网关混沌故障注入规则编排卡片与抽样调节器 (`MeshChaosRuleCard.vue`)**：
  - 支持 503 实例宕机、网关断路熔断 ECONNRESET、网络延迟抖动与报文畸形损坏四大故障单选切换；
  - 流量抽样比例动态滑块支持 0% ~ 100% 精确调节，即时指示全量注入、灰度抽样与完全放行状态；
  - 多维路由与金丝雀请求头标匹配（如 `x-canary=true`）；
  - 支持在线发送试探请求预演故障决策，即时查看状态码、延迟与响应体 JSON 预览。
- **UI3.2 微服务调用依赖拓扑与爆炸半径逆向 BFS 级联阻断图 (`BlastRadiusTopologyGraph.vue`)**：
  - 设定最大允许波及微服务数、最大传导深度以及核心受保护服务名单（如 `user-auth`、`billing-core`）；
  - 判定越界或波及受保护核心服务时，立即弹出亮红告警：`[EMERGENCY ABORT 紧急熔断已触发]`；
  - 基于 ECharts 力导向图全景呈现微服务有向调用依赖拓扑网络（靶点红、直接琥珀、级联橙、受保护紫、健康蓝）。
- **UI3.3 全链路高可用 SLA 韧性评分与自愈 RTO 评级看板 (`MeshResilienceReportView.vue`)**：
  - 注册独立系统中心路由 `/system/mesh-resilience`；
  - 大字号醒目呈现加权总分（0~100）与 Grade A/B/C/D 勋章；
  - 自动定位全链路中最薄弱短板微服务（Weakest Link）并输出云原生高可用加固指引；
  - 四维加权细分：可用性 SLA 达成度（40%）、故障自愈 RTO 时效（30%）、爆炸半径约束控制力（20%）与峰值错误容忍度（10%）。

### Phase 4：企业级 OIDC/SSO 与不可篡改审计安全中心 (IAM, SSO & Tamper-Evident Audit Center)

- **UI4.1 企业级 OIDC / OAuth2 身份提供商接入与单点登录卡片 (`OidcProviderConfigCard.vue`)**：
  - 全景展示 Keycloak、Okta、ADFS 等已接入的企业身份中枢，客户端私钥严格脱敏显示为 `***REDACTED***`；
  - 一键发起 SSO 登录跳转，弹出经密码学随机数生成的防伪 State 与防重放 Nonce 校验参数及 IdP 重定向地址；
  - 支持动态接入新身份提供商弹窗。
- **UI4.2 细粒度资源操作 RBAC 策略模拟器与 Anti-IDOR 诊断抽屉 (`IamPolicySimulatorDrawer.vue`)**：
  - 内置 4 类典型攻防场景快捷载入（测试员篡改用例、工程师擅自销毁密钥、跨项目横向越权、正常用例维护）；
  - 在线模拟策略决策点（PDP）判定，展示 Explicit Allow 绿色横幅与 Explicit Deny 红色横幅；
  - 实时检测并标记 Anti-IDOR 跨项目横向越权状态；
  - 展示平台当前生效的细粒度 RBAC 规则基线清单。
- **UI4.3 类区块链 SHA-256 审计日志哈希链完整性校验与合规证明导出 (`AuditTamperEvidentChainView.vue`)**：
  - 注册独立系统路由 `/system/audit-chain`，并在常规审计日志列表中集成跳转入口；
  - 水平滚动呈现密码学哈希指针链条（前驱哈希、数据摘要、链块哈希与审计操作内容）；
  - 支持一键在线自检与「模拟篡改攻击检测」（篡改发生即刻弹出红色 `TAMPER DETECTED` 严重告警并高亮定位受损区块）；
  - 弹出正式合规证明证书（带 ISO/IEC 27001 & SOC 2 官方防伪绿盾印章与 64 位 HMAC-SHA256 数字签名）。

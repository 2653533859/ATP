## 1. 版本概述 (Executive Summary)

ATP v3.0.0 是自动化测试平台迈向**全协议智能流量录制、移动真机回放自愈、分布式网关混沌演练与企业级合规安全中枢**的里程碑式正式发布版本。

本版本历经 4 大核心研发阶段，共计 12 项重大子系统级技术演进，已实现 100% 全量大闭环交付：
1. **全协议智能流量录制与逆向生成 (Phase 1)**：落地微服务反向代理录制网关与凭据脱敏清洗引擎、多层级 JSONPath 动态参数递归推导提取与 `{{variable}}` 上下文占位符替换，以及自动逆向合成 TestCase、CaseStep、TestSuite 套件资产及数据库原子落库；
2. **移动端真机智能回放与视觉 DOM 混合自愈 (Phase 2)**：构建 Android/iOS 统一回放驱动分发调度器（涵盖点击/输入/滑动/等待/断言与上下文动态渲染）、Tier 1~3 DOM 与 OCR 边界坐标混合智能定位与失效自愈算法，以及 MP4 回放视频毫秒级关键帧对齐与异常高亮报告器；
3. **分布式网关混沌演练与爆炸半径控制 (Phase 3)**：构建多协议网关级微服务混沌故障编排引擎（支持 503 宕机、连接熔断、延迟抖动与畸形报文 4 大故障与流量采样抽样控制）、微服务拓扑图逆向 BFS 级联影响追踪与防雪崩紧急熔断（Emergency Abort），以及四维加权微服务高可用可用性 SLA 韧性评分（Grade A-F）与云原生加固报告；
4. **企业级 OIDC/SSO 认证与合规审计安全中心 (Phase 4)**：支持 Keycloak、Okta、ADFS 等标准 OpenID Connect / OAuth2 身份提供商无缝单点登录集成与防重放 state 校验、基于 RBAC + 细粒度操作资源鉴权决策点（PDP）与 Anti-IDOR 跨项目横向越权隔离，以及类区块链式 SHA-256 防篡改审计日志校验链与导出带数字签名印章的合规报告。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：全协议智能流量录制与逆向生成 (Traffic Ingestion & Case Reverse Engine)

- **T1.1 微服务反向代理流量录制与清洗服务 (`traffic_recorder_gateway`)**：
  - 采用流式会话拦截机制，实时捕获 HTTP/REST 微服务调用；
  - 自动清洗静态资源后缀（`.js`, `.css`, `.png`, `.woff2`）与健康检查探测（`/healthz`, `/livez`）；
  - 敏感认证凭据自动脱敏（`Authorization`, `Cookie`, `X-Api-Key` 替换为 `***REDACTED***`）；
  - 开放 `/api/v1/traffic-recording/*` 统一生命周期管理 API。
- **T1.2 动态参数变量提取与占位符替换算法 (`dynamic_param_extractor`)**：
  - 深度遍历上游响应体叶子标量，动态识别 UUID、Token、Order ID 等候选参数及其 JSONPath；
  - 自动将下游请求的 URL 路径、Query 参数、Headers 及 JSON Body 对应字段替换为 `{{variable}}` 动态插值；
  - 为前置步骤自动注入参数提取提取器规则。
- **T1.3 流量录制会话自动逆向合成为用例套件 (`traffic_to_case_converter`)**：
  - 多维自动生成断言（HTTP 状态码、JSONPath 业务状态、请求耗时 SLA）；
  - 录制清洗流量一键逆向持久化转换为 TestCase、CaseStep 与 TestSuite 套件资产。

### Phase 2：移动端真机智能回放与视觉 DOM 混合自愈 (Device Playback & Self-Healing)

- **T2.1 Android/iOS 统一回放驱动器与生命周期 (`device_playback_driver`)**：
  - 抽象统一 `DevicePlaybackSession`，抹平 Android uiautomator2 与 iOS XCUITest 底层调用差异；
  - 支持 `click`、`input_text`、`swipe`、`press_key`、`wait`、`assert_text`、`screenshot` 等核心动作序列分发；
  - 支持运行时 `{{var}}` 上下文变量动态注入与单步执行耗时审计。
- **T2.2 视觉与 DOM 混合智能定位器与失效自愈 (`visual_dom_hybrid_locator`)**：
  - **Tier 1**: 绝对精确 DOM / 无障碍树属性比对；
  - **Tier 2**: 基于无障碍树的启发式模糊相似度打分（Levenshtein 算法 + 关键词加权）；
  - **Tier 3**: 视觉截图 OCR 物理边界中心坐标推导与动态点击自愈补偿。
- **T2.3 回放步骤视频逐帧对齐与异常高亮报告 (`playback_timeline_reporter`)**：
  - 精准计算执行步骤相对于录屏开始的毫秒级时序偏移与视频帧号（`frame = int(sec * fps)`）；
  - 自动标注失败高亮与自愈高亮关键帧，生成可供交互播放器时间线跳转的排障报告。

### Phase 3：分布式网关混沌演练与爆炸半径控制 (Mesh Chaos & Blast Radius Control)

- **T3.1 多协议微服务网关级混沌故障编排引擎 (`mesh_chaos_orchestrator`)**：
  - 支持按微服务名称（支持 `*` 通配）、路径正则表达式、HTTP 方法与请求头标签（如 `x-canary: true`）精准匹配；
  - 内置 `service_down_503`、`circuit_breaker_trip`、`latency_jitter`、`corrupt_payload` 四大典型故障动作；
  - 支持流量抽样率（0.0 ~ 1.0）与实时审计统计。
- **T3.2 混沌演练影响拓扑与爆炸半径控制 (`blast_radius_controller`)**：
  - 构建微服务有向依赖拓扑图，通过逆向 BFS 递归推导级联受波及的上游微服务调用链；
  - 设定最大影响服务数与最大传导深度硬约束，核心受保护服务设立黑名单；
  - 违规越界自动触发紧急安全中断（Emergency Abort），暂停演练防止生产雪崩。
- **T3.3 全链路服务级高可用 SLA 韧性评分报告 (`service_mesh_resilience_report`)**：
  - 度量可用性 SLA 达成度与跌幅，追踪故障自愈恢复耗时（RTO）；
  - 结合 SLA、自愈耗时、爆炸半径控制力与错误容忍度输出 0~100 加权评分与 Grade A-F 韧性等级。

### Phase 4：企业级 OIDC/SSO 认证与合规审计安全中心 (IAM, SSO & Compliance Audit)

- **T4.1 企业级 OIDC / OAuth2 身份提供商集成 (`oidc_sso_provider`)**：
  - 支持 Keycloak、Okta、ADFS、Azure AD 等标准 OpenID Connect 协议；
  - 密码学安全的随机 `state` / `nonce` 机制，防范 CSRF 与重放攻击；
  - ID Token 颁发者、受众、时效严格校验，企业员工本地账户动态映射与 JWT Token 签发。
- **T4.2 基于 RBAC + 细粒度操作资源鉴权边界 (`fine_grained_iam_policy`)**：
  - 覆盖 `case`、`suite`、`plan`、`device`、`secret`、`dataset`、`mesh_chaos` 细粒度资产；
  - Anti-IDOR 跨项目边界隔离，彻底阻断跨项目水平越权；
  - 策略决策点（PDP）执行显式拒绝优先（Explicit Deny）与最小特权（Default Deny）。
- **T4.3 企业合规审计日志完整性哈希链与安全报表 (`audit_tamper_evident_chain`)**：
  - 基于创世块起点哈希构建类区块链 SHA-256 审计链条；
  - 自检引擎精准定位数据修改（`Payload Hash Mismatch`）与记录删除（`Broken Chain Link`）；
  - 符合 ISO/IEC 27001 与 SOC 2 Type II 标准，附带 HMAC-SHA256 数字印章防伪合规审计报表。

## 1. 版本概述 (Executive Summary)

ATP v2.5.0 是自动化测试平台历经双架构演进后的里程碑式正式发布版本。本版本全面落地了 **Windows 单机轻量模式（SQLite 13 + 本地持久队列 + 绿色便携包）** 与 **Linux 生产级集群模式（PostgreSQL 16 + Redis + Celery + MinIO）** 的无缝切换与彻底隔离架构，全量收口了从 N0 到 N6 的全部 28 项核心演进任务。

同时，v2.5.0 带来了**真机 60FPS 硬件解码实时流与触控**、**接口自动化多步骤场景编排**、**多协议执行体系（GraphQL / WebSocket / gRPC / 流水线）**、**Hermes 智能助手 8 类面板持久草稿** 以及 **现场 14 日零违约连续高精度 SLO 监测**。

## 2. 核心特性发布清单 (Key Highlights)

### 2.1 双模式架构与安全隔离 (Dual-Mode Architecture & Isolation - N3)
- **动态 Cookie 隔离解析**：本地模式生成 `atp_local_access_token` 与 `atp_local_refresh_token`；服务器模式生成 `atp_access_token` 与 `atp_refresh_token`。在任一模式登出仅定向清除该模式会话，绝不影响另一模式会话；
- **全双工 WebSocket 模式隔离**：长连接仅读取当前激活模式的专属令牌，阻断跨模式串流；
- **跨模式请求熔断保护**：前端自动注入 `X-ATP-Client-Mode` 请求头，后端中间件实时校验，模式冲突直接返回 HTTP 409 Conflict，防止向错误后端写入脏数据；
- **SQLite Schema 13 与备份清单**：支持版本 13 自动安全升级与重跑幂等；`manifest.json` SHA-256 清单一致性校验与篡改阻断；
- **绿色免编译便携交付**：内置 `package-windows-standalone-bundle.ps1`，一键生成仅 2.2 MB（含 632 核心文件、静态前端与启停批处理）的独立免配置包。

### 2.2 真机实时流与 APP 自动化工作台 (Android & Scrcpy Live Stream - N2.2)
- **Scrcpy 60FPS 硬件直解与触控**：基于 WebCodecs H.264 Annex-B 与 WebSocket，延迟低于 30ms，支持全屏与自适应缩放；
- **画布触控防死锁与资源清理**：鼠标按键强制过滤非左键点击，杜绝右键上下文菜单导致的 `isMouseDown` 锁死；超时降级显式清理底层流资源；
- **APP 工作台就地用例闭环**：在工作台就地集成 `AndroidCaseDrawer`，支持设备矩阵、APK 绑定、低代码与 UiAutomator2 脚本编写；自动解析项目根模块绑定，彻底根治 Pydantic 422 校验缺陷；针对 0 用例项目提供标准 Empty State 引导卡片。

### 2.3 接口自动化多步场景编排 (API Scenario Orchestration - N2.5)
- **批量编排与依赖链**：支持将单接口调试或用例一键编排为端到端自动化场景（`ApiScenarioOrchestrator`），自动建立步骤依赖链（`depends_on: [i - 1]`）；
- **单步调试与增量合并**：支持单步执行、响应提取与断言测试；保存时采用 `Object.assign` 增量合并，避免重新赋值导致活动步骤与调试结果丢失；
- **项目切换全量清理**：切换项目时全量同步清理上一项目的场景暂存与已选批次。

### 2.4 多协议执行体系与调度防御 (Multi-Protocol Execution - N2.5)
- **GraphQL 执行器**：支持 Query/Mutation、变量模板渲染、JSONPath 提取与错误断言；
- **WebSocket 执行器**：支持双向帧收发、消息断言、超时保护与连接安全清理；
- **gRPC 执行器**：动态编译 Proto，支持 Unary、Client Streaming、Server Streaming 及 Bidi Streaming；
- **多协议流水线**：支持在同一用例内混合编排 HTTP -> WebSocket -> gRPC，上下文变量（`{{var}}`）无缝传递；
- **空步骤调度防御**：`case_dispatch` 在派发前自动拦截未配置执行步骤的协议用例并记为错误终态。

### 2.5 可靠执行与智能中枢闭环 (Reliable Execution & Hermes AI - N1, N4)
- **不可篡改资源身份**：套件、计划与执行命令绑定内部不可伪造的 UUID，彻底消除整数 ID 复用风险；
- **事务投递意图与去重**：投递意图与业务运行同事务提交；执行端原子领取与首次接受凭据防重复执行；
- **Hermes 8 类操作持久草稿**：支持测试计划、Web 录制、接口用例、回归组织、定位器修复、安卓执行、缺陷整理与知识中枢 8 类草稿持久化；
- **并发版本冲突保护**：基于 `expected_updated_at` 严格拦截并发用例修改；重复确认幂等复用。

### 2.6 线上真实基线与 14 天无间断 SLO 监测 (Linux Production Baseline - N5)
- **K3s 现场稳定运行**：远程主机 `CHINAMI-762P0P5` 6 个核心 Pod 持续稳定运行 17 天且 0 重启；
- **连续 14 日零缺口 SLO**：2026-10-01 至 2026-10-14 完整 14 个 UTC 日共 4,032 个采样点，每日 288/288 100% 达成，API 可用性 100%、P95 延迟 95ms、执行成功率 100%、零违约零缺口；
- **数据库升级与回滚全链路实测**：线上真实 PostgreSQL 实例完成从 `0074` 到最新 `0079` 的全量连续升级演练，以及自 `0079` 到 `0074` 的安全反向回滚演练。

## 4. 快速开始与使用指南 (Quick Start)

### 4.1 Windows 免安装便携版启动
下载交付便携归档解压后直接双击运行：
```cmd
start-atp.bat
```
或通过 PowerShell：
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows-standalone.ps1 -Action up -Frontend static
```
服务将立即在本地端口启动：<http://127.0.0.1:8001/>

### 4.2 双模式切换
```powershell
# 切换至本地单机模式（不影响服务器端进程与会话）
powershell -ExecutionPolicy Bypass -File .\scripts\windows-mode.ps1 -Action local

# 切换至服务器模式（默认连接 http://127.0.0.1:5173）
powershell -ExecutionPolicy Bypass -File .\scripts\windows-mode.ps1 -Action server
```

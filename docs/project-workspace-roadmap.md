# 项目工作台开发记录

更新时间：2026-08-11

## 目标

将项目管理从项目 CRUD 页面扩展为测试项目工作台，统一查看项目状态、执行概况和项目下的测试资产，并为后续模板、导入导出和更细粒度权限提供入口。

## 2026-08-11 后续补充

数据集管理已增加项目内 AI 生成入口。生成结果先进入编辑器草稿，不直接创建或覆盖数据集；保存动作仍统一经过 Schema 校验、软/硬策略和版本快照。该入口使用项目绑定的 AI 配置，并对模型输出、行数和序列化大小做边界限制，详见 [`q18-implementation-log-2026-08-07.md`](q18-implementation-log-2026-08-07.md)。

Mock 服务管理已增加项目内 AI 生成入口。用户可以按要求生成新的 Mock 规则，或选中已有规则作为参考；结果先进入可编辑 JSON 预览，确认后才复用普通创建接口保存。原有“AI 生成用例”入口保持不变，避免把测试用例草稿和 Mock 响应规则混为一谈。

## 本次已实现

- 项目卡片进入项目总览，不再直接跳转到用例列表。
- 新增项目总览页面，展示用例数、执行次数、通过率和近 7 日执行次数。
- 新增项目级配置中心，统一展示并跳转到：用例、环境、数据集、变量、Mock、套件、计划、Web 资产和 API 契约。
- 展示项目编码、AI 模型、创建时间、更新时间和项目状态。
- 项目新增 `active / archived` 生命周期状态。
- 项目列表支持归档和恢复；归档项目保留成员查看、删除和恢复入口，项目配置编辑进入只读保护。
- 项目成员管理根据当前项目角色显示可操作状态；editor/viewer 会看到只读原因提示。
- 新增 Alembic 迁移 `20260811_0054_add_project_status`。
- 新建项目支持 `blank / api / web / android / full` 模板；模板会生成基础模块、一个环境和一份可替换的示例数据。
- 项目列表支持复制项目；复制基础信息和模块树，并为新项目生成独立编码、当前操作者 owner 成员关系。
- 复制明确排除成员、密钥、执行记录、环境变量和外部资源，避免跨项目泄露或复用运行态数据。
- 项目列表支持配置 JSON 导出和导入预览；导出包含项目基础信息、模块、环境、非敏感环境变量和脱敏数据集。
- 导入支持 `fail / rename` 冲突策略，并按 AI 模型名称、供应商和模型名尝试匹配已有配置；API Key 等密钥永不导出。
- 导入时跳过被标记为脱敏的变量，当前操作者成为新项目 owner；成员、执行记录、密钥和外部资源不进入传输范围。
- 归档项目的测试资产写入和执行入口统一返回 409；项目配置编辑也返回 409；viewer 读取、报告和项目导出保持可用，恢复项目后自动解除限制。
- 归档项目的复制按钮、成员编辑控件在前端禁用并显示原因；后端新增可写项目依赖，避免绕过 UI。
- 项目复制、导入、归档、恢复和成员变更写入明确的项目审计事件，便于追踪配置生命周期。

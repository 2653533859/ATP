## 1. 版本概述 (Executive Summary)

ATP v3.3.0 是自动化测试平台迈向**集群协同调度、资产拓扑与质量门禁交互控制台全量落地 (Cluster HA Orchestration, Asset Graph & Quality Governance Studio)** 的重大里程碑正式发布版本。

本版本承接 v3.2.0 底层高可用微服务集群协同调度与全景资产治理能力，历经 4 大核心技术阶段共 12 项重大交互控制台与可视化大盘研发展开，已实现 **100% 全量大圆满闭环交付**：
1. **跨节点 Worker 集群协同调度与故障转移监控台 (Phase 1)**：落地 Worker 负载监控抽屉与容量五级分级仪表板（UI1.1）、自适应任务排队水位与 P0 弹性抢占调度控制台（UI1.2）、以及节点失联超时检测与孤儿任务故障转移卡片（UI1.3）；
2. **全域测试资产依赖拓扑与变更影响面控制台 (Phase 2)**：落地基于 ECharts 力导向图的测试资产全景引用拓扑图谱与孤儿资产看板（UI2.1）、接口契约变更影响面分析与受损用例抽屉（UI2.2）、以及变更影响用例自动化精准回归套件合成向导（UI2.3）；
3. **多协议动态仿真沙箱与流量镜像控制台 (Phase 3)**：落地瞬时轻量级仿真沙箱与 20000~29999 端口生命周期管理抽屉（UI3.1）、跨协议数据透传与会话上下文共享总线面板（UI3.2）、以及沙箱网络流量镜像与写操作副作用隔离卡片（UI3.3）；
4. **企业级测试质量度量大盘与质量门禁中心 (Phase 4)**：落地全生命周期测试质量度量多维评分大盘页面（UI4.1）、CI/CD 智能质量门禁规则配置与卡点决策抽屉（UI4.2）、以及自动化发版准入合格证书与防伪数字印章弹窗（UI4.3）。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：跨节点 Worker 集群协同调度与故障转移监控台

- **UI1.1 跨节点 Worker 负载监控抽屉与容量分级仪表板 (`ClusterWorkerMonitorDrawer.vue`)**：
  - 呈现存活活跃节点 / 注册总数对比、总并发槽位占用率、集群平均 CPU/内存负载；
  - 五级容量梯队健康分布标签（`HEALTHY_IDLE`、`MODERATE_LOAD`、`HEAVY_LOAD`、`OVERLOADED`、`OFFLINE`）；
  - 最优节点调度选举算法实时推演与胜出 Worker 节点高亮；
  - 节点状态呼吸灯、并发槽位进度条与负载评分明细流水表格。
- **UI1.2 自适应任务排队水位与 P0 弹性抢占调度控制台 (`AdaptiveTaskQueueDrawer.vue`)**：
  - 四级优先级调度梯队与排队水位统计指标（Running、Queued、Suspended 被挂起等待唤醒）；
  - 任务预计等待时长（ETA）与队列顺位一键测算；
  - 一键模拟提交 P0 紧急抢占任务与 P2 常规回归任务，实时呈现让位抢占高亮反馈；
  - 任务完成释放槽位与挂起任务自动唤醒联动。
- **UI1.3 节点失联超时检测与孤儿任务故障转移卡片 (`WorkerFailoverRecoveryCard.vue`)**：
  - 动态设定节点心跳超时阈值（默认 30 秒）；
  - 一键触发全集群「心跳超时全网巡检 (Sweep Scan)」操作；
  - 呈现累计巡检批次、失联节点数、抢救重入队任务数与熔断保护数 4 大 KPI；
  - 展现失联节点下线标签池、孤儿任务抢救重调度记录（`rescheduled`）与超限安全熔断记录（`aborted`）。

### Phase 2：全域测试资产依赖拓扑与变更影响面控制台

- **UI2.1 测试资产全景引用拓扑图谱与孤儿资产看板 (`AssetDependencyGraphViewer.vue`)**：
  - 基于 ECharts 力导向关系拓扑图呈现 `Plan → Suite → Case → API / Dataset` 全景调用网络；
  - 资产六维类别色彩区分与画布缩放漫游交互；
  - 点击节点即时联动发起正向被依赖项（Downstream）与上游来源项（Upstream）双向链路追溯；
  - 孤儿用例与游离数据源治理预警与清单展示。
- **UI2.2 接口契约变更影响面分析与受损用例抽屉 (`ContractChangeImpactDrawer.vue`)**：
  - 支持 HTTP Method 与 API 路径动态设定；
  - 提供「载入破坏性变更示例」与「载入兼容变更示例」快捷预设；
  - 双栏对比编辑基线 OpenAPI Schema 与当前版本 OpenAPI Schema；
  - 破坏性变更数（Breaking）、潜在告警数（Warnings）、兼容变更数（Compatible）与受损用例数 KPI 概览；
  - 双标签页明细：字段 Diff 变更清单与逆向推导受损用例清单（含受损等级、详细归因与修复方案）。
- **UI2.3 变更影响用例自动化精准回归套件合成向导 (`TargetedRegressionWizard.vue`)**：
  - Step 0：受损用例原子级 ID 去重与表格勾选过滤；
  - Step 1：调度策略与套件配置，支持 Breaking 变更自动提权为 **P0 紧急抢占调度**、套件持久化落库开关与自动触发调度开关；
  - Step 2：合成结果与凭据交付（套件 ID、调度任务 ID、执行优先级与抢占插队横幅）。

### Phase 3：多协议动态仿真沙箱与流量镜像控制台

- **UI3.1 瞬时轻量级仿真沙箱与端口生命周期管理抽屉 (`EphemeralSandboxManagerDrawer.vue`)**：
  - 支持 HTTP、gRPC、WebSocket 单协议及多协议仿真沙箱按需拉起；
  - 动态申请 20000~29999 端口池无冲突独立端口；
  - 活跃沙箱数、占用端口数与过期待收割数运行水位总览；
  - 一键执行全域过期沙箱自动收割（Reap Expired Sandboxes）；
  - 内联 Mock 派发测试弹窗：支持向沙箱实例直接派发 Mock 请求并查看响应 JSON。
- **UI3.2 跨协议数据透传与会话上下文共享总线面板 (`CrossProtocolSessionBusPanel.vue`)**：
  - 支持输入或切换总线会话 ID，一键载入电商全链路预设变量（`user_token`、`order_sn`、`user_id`、`trace_id`）；
  - 全局共享状态变量表与快捷写入表单；
  - 协议凭据上下文主动透传控制台（`HTTP → gRPC` 与 `HTTP → WebSocket`），实时以 JSON 格式预览生成的协议上下文；
  - 动态模板递归插值实时预览：对嵌套 JSON/文本中的 `{{variable}}` 执行递归插值。
- **UI3.3 沙箱网络流量镜像与写操作副作用隔离卡片 (`SandboxTrafficMirrorCard.vue`)**：
  - 在线配置流量镜像分流策略（策略 ID、名称、源服务、路由匹配正则、目标沙箱 ID 与破坏性副作用拦截开关）；
  - 呈现敏感外发写操作强阻断模式池标签（`*payment*`、`*charge*`、`*sms*`、`*notify*`）；
  - 一键「注入镜像流量并验证隔离」，处理模拟业务流并捕获敏感外发写操作；
  - 零泄露合规认证横幅（`[ZERO LEAKAGE 零泄露合规证明]`）与携带 `X-Sandboxed-Isolated: true` 的防穿透响应凭据流水审计。

### Phase 4：企业级测试质量度量大盘与质量门禁中心

- **UI4.1 全生命周期测试质量度量多维评分大盘页面 (`QualityMetricsDashboardView.vue`)**：
  - 独立路由 `/quality/metrics`；
  - 0~100 综合质量健康评分、质量等级（Grade A 绿、Grade B 蓝、Grade C 橙、Grade D 红）与发版准入终审徽标（APPROVED / WARNING / BLOCKED）；
  - 四维加权指标卡片（覆盖率 30%、缺陷逃逸 20%、稳定性 25%、MTTR 25%）；
  - ECharts 四维加权雷达图：当前项目实际得分 vs 卓越基线目标（Benchmark）双层对比；
  - 全生命周期质量改进建议面板（Actionable Insights）；
  - 指标推演模拟器弹窗：在线调节参数实时推演预测最终得分与发版准入评级。
- **UI4.2 CI/CD 智能质量门禁规则配置与卡点决策抽屉 (`QualityGateRuleConfigDrawer.vue`)**：
  - Profile 策略元数据在线编辑与违约阻塞 CI 开关；
  - 一键载入「生产发布阻断预设」与「PR 冒烟准入预设」；
  - 规则表达式矩阵表格：配置指标项、比较算子（≥, >, ≤, <, =）、安全阈值与卡点等级（Blocker 阻断 / Warning 警告）；
  - CI/CD 在线实时卡点判定实测：支持输入指标 JSON，一键判定输出放行（exit_code: 0）或强制阻断（exit_code: 1）；
  - 逐项规则判定决策流水表格：清晰标明实际值 vs 阈值对比与单项达标情况。
- **UI4.3 自动化发版准入合格证书与防伪数字印章弹窗 (`ReleaseCertificateModal.vue`)**：
  - 输入发版版本号、代码 Commit SHA 与发版环境，一键签发企业级发版准入合格证书；
  - 高质感证书纸面设计（暗蓝渐变、防伪虚线框）；
  - 官方安全徽章：`🛡️ ISO 27001 AUDITED`、`🔒 SOC 2 TYPE II COMPLIANT` 与 `⭐ ATP SECURITY TRUSTED`；
  - 仿真官方大印章：`APPROVED` 绿色双圈印章「ATP 质量门禁委员会 · 准予发布」或 `REJECTED` 红色阻断印章；
  - HMAC-SHA256 数字防伪印章签名与 SHA-256 完整性摘要展示；
  - 一键在线核验 HMAC-SHA256 数字印章真实性与防篡改自检；
  - 一键导出下载证书凭据 JSON 文件。

# Hermes 本地测试助手功能完善

日期：2026-09-30。适用于 Windows SQLite＋本地目录与服务器模式。

## 已实现的第一版

助手页增加八个操作入口。聊天中匹配相关请求时打开同一个操作面板，先准备具体内容，再确认保存或执行。操作调用已有项目 API，权限与执行审核仍由后端控制。

| 功能 | 当前实现 | 使用边界 |
| --- | --- | --- |
| 完善录制 | 读取现有 Web 低代码步骤，追加用户提供的文本断言，设置 30 秒超时 | 不猜测业务预期；保存后需沿用审核流程 |
| 生成接口用例 | 解析 cURL、OpenAPI 或 Postman，调用项目模型，预览并选择导入草稿 | 每次 1～20 个接口、最多 5 条草稿；需要已绑定模型和网络；禁止外部引用 |
| 组织回归 | 推荐失败运行对应的可执行用例，也可手动选择；创建串行套件 | 创建与执行分开确认，运行环境由用户选择 |
| 修复定位器 | 分析所选失败运行，展示诊断依据；预览原定位器到新定位器的替换 | 新定位器由用户提供；替换步骤解除原元素资产绑定，避免资产覆盖新定位器；不声称自动自愈 |
| 运行安卓用例 | 核对已有可执行用例、绑定设备在线状态和项目 APK，再提交执行 | 当前支持已有单设备绑定；设备状态来自最近同步，真实 ADB 与安装仍由执行器检查 |
| 整理缺陷 | 从失败用例运行整理步骤、错误与说明，创建并关联缺陷 | 重复时返回已有缺陷；证据沿用原运行 |
| 保存经验 | 将最近回答或用户编辑内容保存为当前项目知识草稿 | 不自动发布知识；可在知识库继续编辑 |
| 测试总结 | 汇总最近 1～30 天的用例运行、当前开放缺陷，导出 Markdown | 滚动时间窗口；运行明细最多 50 条，不包含全部套件或性能专项统计 |

## 提交保护与双模式

- Web 修改提交 `expected_updated_at` 和 `expected_config`。后端条件写入持有数据库锁，刷新状态后检查配置；冲突返回 409，要求重新预览。配置比较覆盖 SQLite 秒级时间戳的同秒修改。该参数为可选，原客户端继续使用现有接口；无数据库迁移。
- 新生成用例沿用草稿与待审核状态，不自动批准或执行。回归套件创建成功后，需要另一次确认才执行。
- 每次面板提交只发送一次写请求；响应不确定时提示先查看记录。该保护仅在当前页面有效，不代替后端持久幂等命令。
- 切换项目清除面板草稿；查看权限不能提交编辑操作。服务器继续使用既有执行路由，本地继续使用单机队列。
- 不新增密钥文件，不向文档写入凭据。模型使用项目既有配置；文件与证据保存沿用运行模式。

## 第二轮完善：保存前编辑与处理记录

- 录制和修复建议复用现有 Web 步骤编辑器，可调整顺序、步骤、定位器与断言；编辑会撤销确认。提交前检查动作所需字段及空步骤，直接修改定位器时解除旧资产引用。
- 接口草稿可修改每个请求的方法、地址和断言，可增加或删除断言。请求其他配置沿用模型草稿并保留完整预览；每个选中的请求必须包含有效断言，数字预期保留数字类型。
- 增加当前浏览器会话的最近处理记录，按用户与项目分开，最多 20 次。只保存操作类型、提交时间、结果编号与入口和状态，不保存请求、草稿或密钥。
- 关闭面板或刷新后可从记录进入结果页面。未确认完成的提交显示“状态待核对”，不自动重试；“已提交成功”只代表接口返回成功，不代表测试运行通过。
- 当前仍未实现服务端持久命令、跨浏览器恢复或自动核对未知请求；关闭浏览器会话后不保证处理记录保留。套件关闭后仍可从套件页手动执行。

本轮只修改前端，保留两种模式的领域 API 与执行逻辑。未新增或运行自动化测试，未提交真实模型请求或业务执行。

第二轮前端类型检查与本地／服务器构建均通过，差异格式检查通过。真实写入、模型生成和设备运行验收仍待执行；处理记录属于浏览器会话记录，不是服务端执行日志。

### 2026-10-04 套件执行编号与状态查询

- `POST /suites/{id}/run` 增加可选命令编号，内容哈希包含套件、环境与覆盖变量。运行与命令记录同事务提交；相同编号返回原运行，不再次投递，不同内容返回 409。
- 创建套件和执行套件同时校验动作类型，避免跨动作复用命令编号。删除后的原运行不会由重复请求重建。

### 2026-10-03 服务端套件创建记录

- 新增 `hermes_actions` 表，按用户和命令编号唯一，保存项目、内容哈希、动作及返回套件编号。创建记录和套件同一事务提交，失败回滚，不保存原始请求或密钥。
- `POST /suites` 可选 `command_id`：相同编号与内容返回原套件，内容冲突返回 409；原套件已删除时不会重建。数据库唯一约束处理并发提交冲突。
- `GET /hermes/action-records` 读取当前用户在指定项目的最近 20 次成功创建记录；仍检查项目访问权限。助手打开操作面板后合并服务端记录，重新登录后可以找回已成功创建的套件。
- SQLite 增加版本 7 升级；服务器必须先应用 Alembic `20261003_0075`。旧客户端未提供命令编号时保持原有创建行为。

- 本轮执行静态检查与双模式前端构建，不运行自动化测试或真实业务执行，不部署 Linux。

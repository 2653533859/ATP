## 1. 版本概述 (Executive Summary)

ATP v3.9.0 是自动化测试平台前端可视化体系迈向**生产流量网关镜像录制、影子回放比对、契约动态漂移防线与混沌韧性演练控制台 (Traffic Guard & Chaos Resilience Frontend Control Consoles, Dashboards & Pipeline Monitor)** 的里程碑式重大突破发布版本。

本版本紧密承接 v3.8.0 交付的后端四大引擎，构建了高度现代化、交互流畅且遵循 UI/UX Pro Max 企业级 SaaS 规范的前端控制面，历经 4 大核心阶段共 12 项重大子系统级技术演进，已实现 **100% 全量大圆满闭环交付**：
1. **生产流量网关镜像捕获、智能脱敏与用例聚类合成控制台 (Phase 1)**：落地微服务网关旁路流量捕获与动态采样过滤抽屉（UI1.1）、生产敏感数据自适应脱敏规则配置与实时清洗弹窗（UI1.2）、真实流量特征聚类归一与自动化测试用例合成卡片（UI1.3）；
2. **影子流量无副作用沙箱回放、动态去噪差分与黄金基线大盘 (Phase 2)**：落地影子流量无副作用沙箱隔离回放与外部 Mock 代理控制台（UI2.1）、响应体动态字段智能去噪与字段级精确差分比对视图（UI2.2）、接口黄金响应基线版本化管理与回归偏离大盘页面（UI2.3）；
3. **实时接口契约动态逆向提取与 Breaking 变更级联防线面板 (Phase 3)**：落地生产流量 OpenAPI 3.0 / Protobuf 3 动态逆向推导与代码预览抽屉（UI3.1）、接口契约非对称破坏性变更 Breaking 评级仲裁卡片（UI3.2）、契约漂移微服务级联依赖拓扑图谱与爆炸半径告警大盘（UI3.3）；
4. **流量驱动的混沌工程故障注入编排与系统韧性监控中心 (Phase 4)**：落地基于流量特征匹配的应用层混沌故障注入编排抽屉（UI4.1）、服务断路器熔断跳闸时延与 RTO 自愈时序分析看板（UI4.2）、生产流量防线 Checkpoint 检查点端到端全景监控看板页面（UI4.3）。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：生产流量网关镜像捕获、智能脱敏与用例聚类合成控制台
- **UI1.1 微服务网关旁路流量捕获与动态采样过滤抽屉 (`TrafficCaptureGatewayDrawer.vue`)**：
  - 集成于 `ApiWorkbenchView.vue` 工具栏，支持一键滑出 1120px 宽幅流量捕获控制台；
  - 支持 HTTP(REST) / gRPC 双协议实时切换、路径与方法正则过滤；
  - 动态采样率滑块 (0%~100%) 精准调控，展示全网已拦截流量、成功捕获数与过滤丢弃数等 5 大 KPI 指标；
  - 实时捕获流量滚动流水，支持点击下钻查看头部元数据、Query 参数与载荷详情。
- **UI1.2 生产敏感数据自适应脱敏规则配置与实时清洗弹窗 (`TrafficDataMaskerModal.vue`)**：
  - 覆盖手机号、身份证、银行卡、邮箱、JWT Token、密码与自定义敏感字段 7 大高敏分类；
  - 策略支持 MASK 掩码遮蔽、HASH 不可逆哈希匿名化与 REDACT 擦除；
  - 内置**左右双栏在线 JSON 实时清洗演练沙箱**：左侧录入含敏感数据的原始 JSON，右侧秒级展示清洗脱敏后高亮代码及已擦除敏感标签列表。
- **UI1.3 真实流量特征聚类归一与自动化测试用例合成卡片 (`TrafficToTestCaseSynthesizerCard.vue`)**：
  - 展示 80%+ 流量聚类压缩去重横幅，直观呈现去重后精简特征流；
  - URL 动态路由参数自动归一化处理（如 `/orders/{id}`）；
  - 列表呈现聚类簇（Cluster）、命中频次、状态码与自动提取的状态码/SLA 断言；
  - 支持一键将选定流量特征批量转出为 ATP 标准测试用例与数据集行。

### Phase 2：影子流量无副作用沙箱回放、动态去噪差分与黄金基线大盘
- **UI2.1 影子流量无副作用沙箱隔离回放与外部 Mock 代理控制台 (`ShadowTrafficReplayConsoleDrawer.vue`)**：
  - 支持四大写防护模式切换（`BLOCK_WRITES` 严格拦截写请求保证 0 脏数据、`SHADOW_HEADER_ONLY` 注入影子标识、`DRY_RUN` 试跑、`ALLOW_ALL` 全量放行）；
  - 针对第三方外部依赖（支付宝/微信支付、短信服务、邮件网关）自动提供安全 Mock 代理拦截展示；
  - QPS 限流滑块（1~200 QPS）动态平滑调控回放速率；
  - 回放流水列表呈现状态标签、耗时与回放响应详情弹窗。
- **UI2.2 响应体动态字段智能去噪与字段级精确差分比对视图 (`TrafficDiffComparatorViewer.vue`)**：
  - 内置 3 套演示预设（完全一致、核心字段篡改、动态时间戳噪声自动消除）；
  - 动态自动过滤时间戳、UUID、随机 Token 等噪声，消除 95%+ 假阳性误报；
  - 环形相似度健康得分指示（0~100%），直观展示两组响应体的匹配度；
  - 左右分栏 Split-Pane 代码比对框配合行级字段差异矩阵（ADDED / DELETED / MODIFIED / TYPE_CHANGED），支持 JSONPath 精确定位。
- **UI2.3 接口黄金响应基线版本化管理与回归偏离大盘页面 (`GoldenResponseBaselineDashboardView.vue`)**：
  - 独立路由页面 `/quality/golden-baselines`，面向多版本黄金响应基线（如 `v1.0-prod-gold`）集中管控；
  - 偏离态势大横幅与大圆环展示全网回归达标率与三级偏离报警徽章（NORMAL / WARNING / CRITICAL）；
  - 表格支持端点搜索与版本过滤，单接口提供实测响应即时差分校验弹窗与原始快照预览。

### Phase 3：实时接口契约动态逆向提取与 Breaking 变更级联防线面板
- **UI3.1 生产流量 OpenAPI 3.0 / Protobuf 3 动态逆向推导与代码预览抽屉 (`LiveContractSchemaExtractorDrawer.vue`)**：
  - 从生产多样本流量中逆向推导必填项（`required`）、候选枚举值（`enum`）及字段类型；
  - 4 大 KPI 看板呈现样本总数、必填属性数、枚举识别数与响应码分支数；
  - 双选项卡支持 OpenAPI 3.0 JSON Schema 树形属性表格与原生 Protobuf 3 IDL 语法高亮及一键复制。
- **UI3.2 接口契约非对称破坏性变更 Breaking 评级仲裁卡片 (`ContractDriftBreakingEvaluatorCard.vue`)**：
  - 严格践行伯斯塔尔健壮性法则（Postel's Law）双向非对称仲裁：
    - 请求体新增必填项或类型漂移判定为 **BREAKING** 阻断；
    - 响应体删除既有属性或枚举缩减判定为 **BREAKING** 阻断；
    - 响应体新增字段判定为 **COMPATIBLE** 宽松向下兼容；
  - 裁决大横幅显示破坏评级、兼容性健康得分与三大指标统计卡片；
  - 字段级差异明细表格呈现变动路径、期望基准 vs 现网实测值并排对比与深度影响分析，在破坏时展示阻断修复指引。
- **UI3.3 契约漂移微服务级联依赖拓扑图谱与爆炸半径告警大盘 (`ContractDriftImpactTopologyView.vue`)**：
  - 独立路由页面 `/quality/contract-drift-topology`；
  - 基于 Vue-ECharts `v-chart` 力导向布局呈现微服务网格拓扑；
  - 节点色彩编码区分破坏源头、直接受损节点与级联波及节点，被破坏字段消费边以红色加粗虚线显著标识；
  - 4 级爆炸半径大徽章（CRITICAL / HIGH / MEDIUM / LOW）与风险指数百分比；
  - 右侧并排展示受损微服务修复指引与定向安全告警派发记录。

### Phase 4：流量驱动的混沌工程故障注入编排与系统韧性监控中心
- **UI4.1 基于流量特征匹配的应用层混沌故障注入编排抽屉 (`TrafficChaosFaultInjectorDrawer.vue`)**：
  - 支持四大故障模式（LATENCY 网络延迟、ERROR_RESPONSE 错误码注入、CORRUPTION 载荷破坏、ABRUPT_DROP 连接断开）；
  - 内置最大触发次数安全熔断保护（Max Trigger Limit）进度展示；
  - 双栏交互：左侧生效规则列表，右侧编排新建表单与在线沙箱流量演练模拟器；
  - 全局混沌演练会话控制栏，支持一键启动/停止全局演练并统计拦截/注入频次。
- **UI4.2 服务断路器熔断跳闸时延与 RTO 自愈时序分析看板 (`ResilienceRtoRecoveryDashboardCard.vue`)**：
  - 量化三大核心韧性指标：断路器跳闸生效时延 (ms)、故障期降级成功率 (%) 与 RTO 自愈恢复时长 (ms)；
  - 输出四级系统韧性评级（EXCELLENT 卓越 / ADEQUATE 合格 / INSUFFICIENT 欠缺 / FRAGILE 脆弱）；
  - 四阶段状态指示条（CLOSED → OPEN → HALF_OPEN → CLOSED）与高频时序采样流表格；
  - 针对性输出专家级微服务韧性加固与断路器调优建议。
- **UI4.3 生产流量防线 Checkpoint 检查点端到端全景监控看板页面 (`TrafficGuardPipelineMonitorView.vue`)**：
  - 独立路由页面 `/quality/traffic-guard-pipeline`；
  - 四阶段检查点卡点流看板（Stage 1 捕获脱敏 → Stage 2 影子回放差分 → Stage 3 契约破坏阻断 → Stage 4 混沌韧性自愈）；
  - 规范化 Exit Code 0/1/2 裁决大横幅；
  - 高对比度 ANSI 终端控制台日志输出框，带行号与 ANSI 颜色高亮解析，支持一键复制完整终端日志；
  - 右侧提供流水线卡点阻断与处置指引，以及历史执行批次切换记录。

## 1. 目标与范围 (Goals & Scope)

在 v2.8.0 实现弱网仿真模型、AI 状态树自主探索、持续性能基准/混沌 RTO/容量预测，以及多租户配额与 FinOps 报表后端能力 100% 闭环的基础之上，**v2.9.0 聚焦于全栈前端交互控制台与端到端可视化闭环**：

1. **弱网与网络仿真交互工作台 (Network Emulation Studio)**：可视化配置 7 类弱网档案，直观展示 HAR 抓包流量瀑布流、慢请求 Top 5 与抗弱网韧性雷达图；
2. **AI 自主探索与用例生成可视化控制台 (Autonomous Exploration Console)**：展示页面状态树（FSM）拓扑与状态指纹，支持探索事件流实时轨迹、去噪折叠与一键生成 TestCase，并展示熔断告警卡片；
3. **持续性能混沌与容量预测图表视图 (Performance Chaos & Capacity Forecaster)**：展示基线自动打标、漂移偏离度告警、混沌故障注入与自愈 RTO 恢复时间线，以及一阶与二阶多项式回归容量预测图表；
4. **多租户资源配额与企业 FinOps 成本中心 (Multi-Tenant Quota & FinOps Cost Center)**：支持多租户项目配额动态调整、MinIO 资产生命周期清理交互抽屉，以及 FinOps 成本分摊透视表与 CSV 导出看板。

## 3. 质量门禁规则

1. **类型安全与构建验证**：`npm run type-check` (`vue-tsc --noEmit`) 与 `npm run build` 保持 100% 成功。
2. **单元测试与组件覆盖**：每个新功能配备独立 Vitest 单元测试并通过 `npm test`。
3. **交互规范一致性**：严格契合 Ant Design Vue 4.x 设计令牌与双主题（`data-theme="light|dark"`）规范。

## 1. 版本概述 (Executive Summary)

ATP v2.8.0 是自动化测试平台迈向**移动弱网仿真、AI 智能遍历探索、持续性能压测与多租户 FinOps 成本治理**的里程碑正式发布版本。

本版本历经 4 大阶段共 12 项重大特性演进，全面落地了：
1. **移动端弱网与网络仿真自动化 (Phase 1)**：覆盖 2G/3G/4G/离线/高丢包等 7 类网络档案，自动生成 CDP 与 Android ADB tc netem 指令，支持 HAR 抓包深度解析与 DNS/连接重置故障注入；
2. **智能用例自动化冒烟生成与自愈 (Phase 2)**：实现基于 DOM / Accessibility 树的有限状态机遍历引擎与置换不变指纹，探索事件流自动合并提炼为 TestCase 资产，以及死循环振荡与黑屏熔断保护；
3. **性能基准自动化持续压测与降级演练 (Phase 3)**：支持自动 Baseline 晋升打标与 RPS/P95 恶化告警，压力下 4 类混沌故障注入与自愈 RTO 秒级测定，以及纯数学一阶线性与二阶多项式回归容量预测模型；
4. **企业级多租户资源配额与成本分析 (Phase 4)**：建立项目级并发配额与单任务硬超时收割器，多分类测试资产（视频/截图/日志）MinIO 生命周期自动清理，以及多租户 Worker CPU-核时与存储空间 FinOps 成本账单报表导出。

## 2. 核心特性发布清单 (Key Highlights by Phase)

### Phase 1：移动端弱网与网络仿真自动化 (Mobile Network Simulation)

- **Q1.1 弱网仿真配置与延迟丢包模型**：
  - 落地 `network_simulation` 服务，建立 2G、3G、4G、高延迟、高丢包、卫星网络与离线 7 类仿真档案；
  - 自动根据配置生成 Web 端 CDP `Network.emulateNetworkConditions` 与移动端 Android ADB `tc netem` 注入指令；
  - 开放 `/api/v1/network-profiles/*` 系列 REST 端点。
- **Q1.2 弱网专项任务调度与用例指标采集**：
  - 落地 `network_simulation_scheduler` 服务，实现自动化执行前环境注入与执行后安全恢复（`tear_down`）；
  - 落地 `NetworkMetricsCollector`，实时记录实测延迟、丢包率与超时计数，输出抗弱网韧性评分。
- **Q1.3 网络流量抓包与故障注入分析**：
  - 落地 `network_fault_injector` 服务，解析标准 HAR 1.2 抓包文件并提取慢请求 Top 5 与流量统计；
  - 支持 DNS 劫持/NXDOMAIN、TCP 连接重置（ECONNRESET）、超时与 HTTP 5xx 故障模拟。

---

### Phase 2：智能用例自动化冒烟生成与自愈 (AI Autonomous Exploration)

- **Q2.1 基于状态树的智能探索遍历引擎**：
  - 落地 `autonomous_exploration_engine` 服务，实现 DOM / Accessibility 树节点置换不变指纹哈希（`compute_page_state_hash`）；
  - 构建有限状态机（FSM）图模型，具备 2 节点/3 节点乒乓死循环自动识别与 Back 自动脱困能力。
- **Q2.2 探索事件序列自动合成为 TestCase**：
  - 落地 `exploration_case_synthesizer` 服务，执行连续快速点击去噪、输入折叠压缩与有效路径提取；
  - 自动提炼 `CaseStepCreate` 步骤资产，生成执行器配置与页面终态文本断言并持久化落库。
- **Q2.3 异常崩溃与死循环探索熔断保护**：
  - 落地 `exploration_circuit_breaker` 状态机，监控连续黑屏（元素为 0）、动作连续失败、深层振荡与最大步数超限；
  - 图模型自动终止 runaway 探索会话并下发 `action_type="abort"` 与明确的中文熔断原因。

---

### Phase 3：性能基准自动化持续压测与降级演练 (Continuous Performance & Chaos)

- **Q3.1 定时自动化性能基准打标与趋势偏移告警**：
  - 落地 `performance_baseline_alignment` 服务，实现最新成功压测运行具备资格时的自动 Baseline 晋升打标；
  - 自动比对 RPS 严重下跌（>=15%）、P95 延迟恶化（>=20%）与错误率跳变（>=2%），输出告警评估清单与一键晋升端点。
- **Q3.2 压力下故障注入与混沌恢复时长测定**：
  - 落地 `performance_chaos_rto` 服务，编排 4 类主流混沌故障注入（503 宕机、延迟尖刺、丢包、连接重置）；
  - 创新设计**持续健康滑动窗口防抖机制（Anti-Jitter Window）**，高精度测定自愈恢复时长（RTO 秒数）与 Grade A-F 韧性评级。
- **Q3.3 多维性能对比与容量预测模型**：
  - 落地 `performance_capacity_forecaster` 服务，支持多轮压测报告横截面比对与单并发扩展效能比（RPS / VU）计算；
  - 纯数学零依赖实现一阶线性与二阶多项式高斯消元回归，反解 SLA 约束下的集群最大安全承载容量（$VU_{\max}$）与饱和拐点（Knee Point）。

---

### Phase 4：企业级多租户资源配额与成本分析 (Multi-Tenant Quota & FinOps)

- **Q4.1 项目级并发配额与执行时长硬限制**：
  - 建立 `ProjectQuota` 实体模型与 `20261016_0082` 数据库迁移；
  - 落地 `project_quota_manager` 服务，实现跨套件/计划/压测多租户实时并发控制（支持 reject 或 queue）与每日执行累计时长限制；
  - 自动收割超过单任务时限的僵尸长任务，保障 Worker 节点不被霸占。
- **Q4.2 测试资产存储生命周期与自动归档清理**：
  - 落地 `asset_lifecycle_cleaner` 服务，建立视频（7d）、截图（14d）、Traces（14d）、报告与日志（30d）分级保留生命周期；
  - 实现 MinIO 存储定期扫描、Dry-Run 预测、物理安全清理与数据库孤儿引用自动清除。
- **Q4.3 平台计算与存储资源成本统计报表导出**：
  - 落地 `finops_cost_reporter` 服务与 `api/v1/finops.py` 路由，等效折算 Worker CPU-核时与存储空间占用；
  - 输出多租户账单占比与智能 FinOps 降本建议，支持带 UTF-8 BOM 头的 Excel 兼容 CSV 文件导出。
